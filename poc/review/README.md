# 화면 6 POC — 전체 리뷰 (기록 탭은 로드맵)

> v6 (2026-09-15): 기록 화면(8)은 MVP에서 삭제되어 이 POC의 "기록" 탭과 `HistoryStore`는 로드맵(R-02)용으로만 남김. 합산·보정(`computeSummary`)과 비교 이미지 정렬은 그대로 쓰되, 비교 대상은 얹어보기가 아니라 **쌩얼(촬영 1) vs 내 화장**.

## 실행
```
cd poc/review
node tests.mjs                 # 자동 검증 18개
python -m http.server 8000     # 브라우저 데모 → http://localhost:8000
```
(비교 이미지 정렬은 MediaPipe 모델을 CDN에서 받으므로 인터넷 필요. 나머지는 오프라인 동작.)

## 파일
| 파일 | 내용 |
|---|---|
| `core.js` | 순수 함수: `computeSummary`(합산·보정), `upsertPart`(재확인 덮어쓰기), `topMisses`(자주 틀리는 부위), `trendSeries`, `lightingDiffers`, `HistoryStore`(보관 상한·삭제) |
| `tests.mjs` | Node 검증 18개 (A 합산 8, B 보정·멱등 3, C 기록 7) |
| `tests-browser.js` | 같은 케이스의 브라우저 러너 |
| `index.html` / `app.js` / `style.css` | 데모: 부위 결과 편집 → 리뷰 화면, 비교 이미지 정렬(MediaPipe), 기록 저장(localStorage), 추이·자주 틀리는 부위·상세·삭제 |
