# 화면 6 POC — 전체 리뷰 (v6)

폰 목업 + 시연 패널. v6 확정 규칙대로 동작한다.

- 합산은 룩 5부위(눈썹·아이라이너·섀도우·입술·볼터치)만, 화면에는 **합산 숫자만**(기준 표기·보정 표시 없음. 보정은 내부 계산).
- 쉐딩·하이라이트는 **항상 "확인만"**, 합산·대칭 보정에서 제외. 한 줄 평은 "확인하고 넘어가세요" + 좌우 방향.
- 막대 6줄: 부위명 · 점수 또는 "확인만/건너뜀/진행 중/미시작" 칩 · 한 줄 평(숫자 없음). 막대 탭 → 그 단계로 이동(토스트로 대체).
- 쌩얼(촬영 1) vs 내 화장(리뷰 프레임) 나란히 두 장. 랜드마크로 같은 크롭.
- **결과 저장**: 합산·막대·두 사진을 1080×1350 이미지 한 장으로 만들어 Web Share(파일) 또는 다운로드. 서버 전송 없음.
- **끝내기**: 세션 임시 저장(localStorage) 삭제 → "세션이 끝났어요" 화면.
- 기록 화면은 없다. `core.js`의 `HistoryStore`·`topMisses`·`trendSeries`는 로드맵(R-02)용으로만 남겨 두었고 UI에서 쓰지 않는다.

## 실행
```
cd poc/screen6
node tests.mjs                 # 자동 검증 24개
python -m http.server 8000     # → http://localhost:8000
```
사진 정렬만 MediaPipe 모델을 CDN에서 받으므로 인터넷이 필요하다. 나머지는 오프라인.

## 앱으로 옮길 때
- `core.js`를 그대로(웹) 또는 Kotlin 순수 함수로(앱) 이식. 테스트 케이스도 함께.
- 세션 임시 저장은 웹 IndexedDB/localStorage, 앱은 내부 파일. 끝내기 시 전부 삭제.
- 한 줄 평 문장과 `diagnosisCodes`는 채점 모듈과 합의한 코드표로 교체.
