# 당화응 전체 POC — 화면 1 → 6 (v6)

화면별 POC(브랜치 `poc/screen2`·`poc/screen3`·`poc/screen4`·`poc/screen5`·`poc/screen6`)를 한 흐름으로 묶은 것. 폰 목업 하나에서 **동의 → 촬영 4장 → 서버 처리(시뮬레이션) → 룩 10개 → 전체 완성 예상 → [완성본 → 실시간 테두리 → 결과] × 6부위 → 전체 리뷰 → 끝내기** 가 끝까지 돈다.

## 실행
```
# 저장소 루트에서 (샘플 사진 폴더를 같이 서빙)
python -m http.server 8000
# → http://localhost:8000/poc/full/
cd poc/full && node tests.mjs        # 흐름·촬영 게이트·세션·룩·얼굴형 검증 12개
```
- **샘플 모드**(기본): 패널에서 person_N 을 고르면 촬영 4장이 그 세트로 채워지고, 확인받기 때 "가상 화장"(룩 파라미터 + 선택한 편차)을 얹어 채점한다. 카메라 없이 전 흐름을 볼 수 있다.
- **카메라 모드**: 패널 "카메라". 촬영 4장은 조건이 맞으면 자동 셔터(정면 눈 뜸 → 눈 감음 → 왼쪽 45° → 오른쪽 45°), 실시간 테두리는 웹캠에 붙는다. "가상 화장"을 끄면 실제로 그린 화장을 채점한다.
- 폰에서: `http://<PC IP>:8000/poc/full/#device` (목업이 화면 전체, 실제 방향 사용. 카메라는 https 또는 localhost 필요).
- URL 해시로 바로 가기: `#sample=2&screen=review` (앞 단계를 샘플로 자동 채움), `screen` = consent·capture·looks·fullrender·guide·live·result·review, `orient=landscape`, `verify`.
