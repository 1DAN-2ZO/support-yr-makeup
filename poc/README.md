# 당화응 POC

서비스 핵심 루프 하나를 브라우저에서 검증하는 최소 구현.
웹캠 → 얼굴 랜드마크 → 아이라이너 가이드 오버레이 + 눈 확대 → 맨얼굴 기준 저장 → 화장 후 확인 → 가이드 대비 채점.

3D 메시·FLAME 없음. MediaPipe Face Landmarker(468점 + 홍채) 랜드마크만 사용.

## 실행

카메라는 `localhost` 또는 https에서만 열린다. 파일을 더블클릭하면 안 되고 로컬 서버가 필요하다.

```
cd poc
python -m http.server 8000
```

크롬에서 `http://localhost:8000` 접속 → 카메라 허용.
모델(약 4MB)과 WASM은 첫 로딩 때 CDN에서 받는다.

## 모드

- **사진 모드 (기본)**: 맨얼굴 사진과 화장 후 사진 2장을 올리면 즉시 채점. 슬라이더를 바꾸면 재채점.
- **카메라 모드**: 헤더에서 전환. 웹캠으로 기준 저장 → 화장 → 확인 (각 5프레임 평균).

## 사용 순서 (사진 모드)

1. 같은 자리·같은 조명·비슷한 거리에서 맨얼굴 사진과 화장 후 사진을 찍는다. 정면, 눈 뜬 상태.
2. 두 장을 올린다. 얼굴 검출과 척도(홍채)가 각 사진 아래 표시된다.
3. "확인할 눈" 선택, 가이드 슬라이더로 점선 조정. 결과가 즉시 갱신된다.
4. 화장 후 사진 위에 판정 점이 찍힌다. 검정 = 밴드 안 변화, 빨강 = 밴드 밖 변화.

## 사용 순서 (카메라 모드)

1. 정면, 조명 고정. "확인할 눈" 선택.
2. **1. 맨얼굴 기준 저장** — 5프레임 평균.
3. 아이라이너(또는 수성 펜)로 한쪽 눈 위 눈꺼풀 라인을 그린다. 카메라·자리·조명 유지.
4. **2. 화장 후 확인** — 5프레임 평균으로 채점.

## 무엇을 재나

| 항목 | 방법 |
|---|---|
| 가이드 안 채움 | 가이드 밴드(선 두께 폭) 안에서 ΔE가 임계 이상인 샘플 비율 |
| 선 두께 | 각 위치에서 임계 이상인 폭의 중앙값, 홍채 지름(11.7mm 가정)으로 mm 환산 |
| 꼬리 길이 | 꼬리 구간에서 그려진 끝 지점 vs 가이드 끝, mm |
| 밴드 밖 이탈 | 밴드 바깥에서 임계 이상인 샘플 비율 |
| 좌우 지수 | 눈별 밴드 내 평균 ΔE를 0~100으로 (ΔE 30 = 100) |
| 볼 발림 지수 | 볼 폴리곤 평균 ΔE, 좌우 |
| 피부 대비 밝기 차 | (볼 L* − 이마 L*)확인 − (볼 L* − 이마 L*)기준 |
| 조명 보정 | 이마 L* 비율로 현재 프레임 L* 스케일 |
| 자세 차이 | 두 사진의 눈 너비 비율. 1에서 15% 이상 벗어나면 경고 |

## 한계 (의도적)

- 고개가 돌아가면 눈꺼풀 샘플링이 어긋난다. 정면 유지 전제.
- 조명이 바뀌면 이마 보정만으로는 부족하다. 이마 밝기 변화가 크면 경고만 표시.
- 눈 감은 상태·손 가림 처리 없음. 확인 시 눈을 뜬 상태로.
- 톤 환산(1톤 ≈ ΔL* 4)과 목표 밴드는 임시 가정값.
