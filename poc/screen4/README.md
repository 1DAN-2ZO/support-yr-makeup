# 화면 4 POC — 실시간 테두리 (v6)

라이브 프리뷰가 화면 전체를 채우고, 그 위에 그릴 자리 **테두리(선만)** 가 매 프레임 랜드마크에 붙어 따라간다.
화면에 두는 것은 **진행 칩 6개 · 품질 게이트 한 줄 · 구석의 작은 "확인받기"** 뿐이다. 제품 안내·근거·자리 비움 문구·건너뛰기는 없다.

## 실행
```
# 저장소 루트에서 (샘플 사진 폴더를 같이 서빙해야 함)
python -m http.server 8000
# → http://localhost:8000/poc/screen4/
cd poc/screen4 && node tests.mjs        # 자동 검증 26개
```
- 기본 소스는 촬영 세트 샘플(`danghaeung_poc_3x4_20/person_1_front_closed.jpg`). "카메라"를 누르면 웹캠(거울 모드).
- 폰에서 직접: 같은 네트워크에서 `http://<PC IP>:8000/poc/screen4/#device` — 목업이 화면 전체가 되고, 실제 폰 방향을 따른다. 카메라는 https 또는 localhost에서만 열리므로 폰에서는 터널(예: `ngrok http 8000`)이 필요할 수 있다.
- URL 해시: `#part=liner&orient=landscape&src=<이미지 경로>&nohand&cam&verify`.

## 화면 요소 ↔ 문서 (impl-screen1-5-definition-v6.md 3-1, 3-3, 3-4)
| 요소 | 구현 |
|---|---|
| 3-1 진행 칩 6개 | 왼쪽 위 반투명 칩. 부위명 · 상태(미시작/진행 중/완료/확인만/건너뜀) · 점수. 탭 → 그 단계로 |
| 3-2 방향 안내 | 눈·눈썹 단계 + 세로 폰 → "폰을 가로로 돌리세요" 오버레이, 세로 부위 + 가로 폰 → "폰을 세로로 돌리세요". 맞으면 사라짐. 세로로 계속 들면 양쪽 눈을 작게 + "확대 낮음" |
| 3-3 확대 프리뷰 | 눈 단계: 양쪽 눈 끝에서 끝 + 여백 15%. 입술 2.5~3배, 볼·쉐딩은 얼굴 폭 기준. EMA 떨림 제거, 거울 모드(카메라) |
| 3-4 가이드 오버레이 | `guides.js`: 부위별 점선 테두리·꼬리 선·방향 화살표·기준선. 면 채우기 없음, 숫자 라벨 없음(쉐딩·하이라이트만 글자 라벨) |
| 3-6b 레이아웃 | 카드 없음. 프리뷰 전체 + 칩 + 게이트 한 줄 + 구석 원형 버튼 |
| 3-7 품질 게이트 | 정면(yaw ±15°, pitch ±10°) → 부위 가시 → 손 → 선명(라플라시안 분산) → 밝기(이마 L* 기준 ±12) → 안정 5프레임. **가장 먼저 걸린 조건 하나만** 문구. 다 맞으면 "확인받을 준비 됨" |
| 3-8 버튼 | "확인받기"만. 게이트 충족 시 활성, 누르면 **즉시 촬영**(플래시) → 완료 처리 → 다음 부위로. 화면 5 채점은 범위 밖 |
| 3-9 자리 비움 | 화면 문구 없음. 얼굴 미검출이면 테두리만 사라지고 다시 잡히면 붙음. 내부 `presence`(3초) 는 "내부 상태" 탭에서만 |
| 3-4 상태 | guide_shown → ready → capturing → (result) / away. 세션 draft는 상태 바뀔 때 localStorage |

## 파일
| 파일 | 내용 |
|---|---|
| `core.js` | 순수 로직: 진행 칩, 방향 안내, 게이트(`evaluateGate`), 안정 카운터, 자리 비움, EMA, 크롭 박스(`cropSpec`), 가시성, 각도, 세션 draft, L*·라플라시안 |
| `guides.js` | 부위별 GuideSet(테두리·선·화살표·라벨) 생성. 템플릿 고정값(각도·mm), 위치·크기만 랜드마크에 맞춤. 홍채 11.7mm 척도, EAR 눈 감김 |
| `app.js` | MediaPipe Face Landmarker(478점 + 변환 행렬) + Hand Landmarker(손 겹침). 소스(카메라/파일/샘플), 렌더 루프, 확인받기 촬영, 패널 |
| `tests.mjs` / `tests-browser.js` | Node 검증 26개 / 같은 케이스 브라우저 러너(검증 탭). 합성 얼굴 랜드마크로 크롭·가이드·게이트 검사 |
| `screenshots/` | 헤드리스 크롬 캡처: 아이라이너(가로·세로), 눈썹, 섀도우, 입술, 볼터치, 쉐딩·하이라이트 |

## 아직 없는 것 (앱 단계)
- 쉐딩·하이라이트 가이드는 랜드마크 근사(둥근형 예시). 서버 법선 맵·얼굴형 5종 규칙은 미연결.
- 룩 템플릿 값은 `guides.js`의 TEMPLATE 한 벌(스모키 가정). 10개 룩 확정 후 교체.
- 카메라 저속 전환(자리 비움 3초)은 상태만 바뀌고 실제 프레임 레이트는 안 낮춘다.
