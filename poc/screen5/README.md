# 화면 5·5-b POC — 부위 결과 (v6)

확인받기 결과 화면. **점수(또는 "확인만") + 내 화장 사진 위 가이드 테두리 + 한 줄 평**, 버튼은 **다음 / 건너뛰기** 뿐(재시도 없음, 점수가 낮아도 다음 가능).
숫자(mm·각도·%)는 화면에 없고 시연 패널의 "내부 지표" 탭에만 있다. 쉐딩·하이라이트는 항상 "확인만".

## 실행
```
# 저장소 루트에서 (샘플 사진 폴더를 같이 서빙)
python -m http.server 8000
# → http://localhost:8000/poc/screen5/
cd poc/screen5 && node tests.mjs        # 자동 검증 27개
```
URL 해시: `#part=liner&preset=wing_high_r&sample=person_2_front_open.jpg`, `#sweep=1`(전 부위 프리셋 스윕), `#dbg=1`(감지 샘플 표시), `#verify`.

## 어떻게 채점하나
1. **입력 두 장**: 쌩얼(촬영 1)과 내 화장(확인받기 프레임). POC에서는 "가상 화장"으로 쌩얼 위에 편차를 알고 화장을 그려 넣는다(프리셋: 잘 됨 / 오른쪽 꼬리 위로 / 두껍게 / 아래 경계 밖 / 오른쪽 진하게 / 화장 안 함 …). 실제 두 장을 올려도 된다.
2. **랜드마크 정렬**(문서 5-2): 내 화장 사진에서 랜드마크를 다시 검출하되, 화장 부위 점은 쓰지 않는다. 눈 끝·콧대·얼굴 옆·턱·이마 등 **안정 점 16개로 유사변환(크기·회전·이동)** 을 구해 **쌩얼 랜드마크를 현재 프레임으로 옮긴다**. 화장 때문에 랜드마크가 밀리는 편향(입술을 크게 그리면 입술 점이 따라가는 문제)을 막는다. 편향량은 내부 지표에 px로 표시된다.
3. **같은 mm 격자로 샘플링**: 두 사진을 각자의 랜드마크 위치에서 같은 격자(라이너: 속눈썹 선+꼬리를 따라 법선 −3…+3mm 0.25mm 간격 80행, 입술: 윤곽 60점 × 같은 오프셋, 눈썹: 24×9 매개변수 격자, 강도 부위: 영역 평균 + 인접 링 참조 + 이마)로 Lab을 뽑는다. 픽셀 단위 정합이 필요 없다.
4. **조명 보정**: 이마 L* 비율로 현재 Lab의 L을 스케일. 이마 L* 차가 ±12를 넘으면 "조명이 달라져서 재지 못했어요" → 확인만.
5. **ΔE → 지표 → 점수 → 진단 코드 → 한 줄 평**
   - 형태(눈썹·라이너·입술): 겹침(가이드 밴드 안에 감지가 있는 행 비율), 밖 번짐, 두께, 꼬리 길이·이탈 방향, 좌우 차. `score = 100 − (1−겹침)·50 − min(번짐·60,30) − min(|꼬리Δ|·8,20) − min(|두께Δ|·5,10)` (문서 5-3).
   - 강도(섀도우·볼터치): 유무(부위 ΔE − 참조 ΔE > t), 세션 내 지수 `clamp(Δ/25·100)`, 좌우 지수, 목표 밴드 판정(초과/미달/적당), 섀도우 방향(눈꼬리 쪽 ΔE > 안쪽). 밴드 없으면 "확인만".
   - 쉐딩·하이라이트: 항상 "확인만", 좌우 지수 차 ≥10 이면 "오른쪽/왼쪽이 조금 진해요"만.
   - 측정 불가(화장 감지 안 됨·조명 급변·얼굴 없음·밴드 없음) → 점수 자리에 "확인만" + 이유 한 줄, "다음"은 그대로.
6. **한 줄 평**: 진단 코드 → 문장(숫자 없음, 최대 2문장). 화면 6과 같은 코드표.

## 검증
- `node tests.mjs` 27개: 채점식 상한, 라이너 6종 편차, 눈썹 3종, 입술 3종, 강도 지수·밴드·점수, 쉐딩 확인만, 확인만 이유 4종, 문구 숫자 없음, 다음·건너뛰기·재확인, 유사변환 복원·편향 측정.
- **프리셋 스윕**(검증 탭 또는 `#sweep=1`): 6부위 × 프리셋 26개를 가상 화장으로 만들어 기대 코드·상태와 대조. 샘플 `person_2_front_open` 기준 **26/26 통과** (2026-09-16).
- 반복 채점 편차: 검증 탭 "같은 입력 5회".

## 가정값·한계 (2단계 실험으로 정함)
- ΔE 임계 라이너 14 / 눈썹 10(맨얼굴에서 어두운 털 위는 5) / 입술 10, 유무 임계 섀도우 5·볼 4·쉐딩 4, ΔE_max 25, 밴드 볼 [25,60]·섀도우 [20,65], 꼬리 이탈 ±0.6mm, 두께 +0.4mm, 비움 25%, 좌우 지수 차 12(쉐딩 10). 전부 `core.js`의 `PARAMS`.
- 가상 화장은 같은 사진 위에 그리므로 자세·조명 변화가 없다. 실제 두 장에서는 유사변환으로 못 잡는 표정·각도 차이가 남는다(문서 3-5의 "같은 자세일 때만 확인" 게이트가 이를 줄인다).
- 화장 영역 시맨틱 분할 모델(문서 5-2 정밀화)은 없고 ΔE 임계 영역만 쓴다. 손 마스크 제외도 없다.
- 눈썹은 털 위에서 펜슬 변화가 작아 겹침이 사람에 따라 낮게 나올 수 있다.
