# 실시간 화장 얹어보기 (poc3d)

카메라 영상에 화장을 실시간으로 입힌다. 소다(SODA)·센스타임이 쓰는
**"표준 얼굴 판에 그려 두고 얼굴 점에 맞춰 입히는"** 방식이다.

## 돌리는 법

머리카락 분할 모델만 따로 받으면 된다 (16MB, 용량이 커서 저장소에 넣지 않았다).

```bash
mkdir -p models
curl -L -o models/selfie_multiclass_256x256.tflite \
  https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_multiclass_256x256/float32/latest/selfie_multiclass_256x256.tflite
```

그다음 이 폴더를 서버로 띄우고 `poc3d.html` 을 연다. 카메라를 쓰므로
**`file://` 로 열면 안 되고**, localhost 이거나 HTTPS 여야 한다.

```bash
python3 -m http.server 8090
# http://127.0.0.1:8090/poc3d.html
```

모델이 없어도 돌아가지만 머리카락 깎기가 꺼져서 앞머리에 화장이 묻는다.

## 들어 있는 룩

라이너 모양만 다르고 나머지는 같다. 섀도·눈썹·얼굴형은 전부 슬라이더로 조절한다.

| 룩 | 라이너 |
|---|---|
| a | 가는 캣아이 |
| b | 굵은 윙 볼륨 (기본) |
| c | 둥근 돌리 |

## 어떻게 입히나

| 층 | 방식 | 무엇 |
|---|---|---|
| 눈썹 다듬기 | 주변 피부로 덮기 | 일자·아치형·올린 |
| 곱하기 | 원래 색에 1보다 작은 수를 곱한다 | 라이너·볼터치·눈 아래·눈두덩 섀도 |
| 소프트라이트 | 밝기를 조절하되 명암은 살린다 | 톤업·애교살·물광 |
| 입술 | 마스크 + 색·명암 지도 | 오버립 3단계 |
| 속눈썹 | 눈 윤곽 9점을 따르는 띠 | 윗·아랫속눈썹·아랫라이너 |
| 얼굴형 | 영상을 읽는 자리를 밀어 좁힌다 | 턱 깎기·광대 좁히기 |

**속눈썹만 판이 아니라 띠로 따로 올린다.** 표준 얼굴 판은 피부를 펼친 지도라
피부에 바르는 화장만 자리가 있는데, 속눈썹은 눈 구멍 위로 튀어나온 털이라
판에 그리면 눈꺼풀 피부에 달라붙기 때문이다.

**얼굴형은 쉐딩이 아니라 실제로 모양을 바꾼다.** 그물만 당기면 원래 턱이 뒤에
남으므로, 영상을 읽어 오는 자리를 바깥으로 밀어 더 바깥의 살이 그 자리에 찍히게 한다.

## 슬라이더

20개다. 화면의 기본값은 눈으로 맞춰 둔 값이니 그대로 두고 시작하면 된다.
`진단` 버튼은 화장과 얼굴형을 하나씩 꺼 가며 어느 층이 문제인지 가릴 때 쓴다.

## 판을 다시 만들려면

판 PNG 는 표준 얼굴 판(2072×2768)에 그린 그림을 UV 로 구운 것이다.
굽는 스크립트는 이 저장소에 없다 — 다시 만들 일이 있으면 전지원에게 문의.
