# 당화응 데이터 계획 — 쉬운 말 판 (2026-09-17)

📌 우리 앱을 만들려면 어떤 사진과 자료가 필요한지, 왜 필요한지, 어디서 어떻게 구하는지를 처음 보는 사람도 알 수 있게 쓴 문서. 전문 용어와 기능 번호는 뺐다. 자세한 근거와 실측 수치는 저장소 `docs/data-plan-v6.md`, `docs/datasets-ranked-v6.md`에 있다.

---

## 1. 왜 사진이 이렇게 많이 필요한가

당화응은 이렇게 돈다. **맨얼굴을 찍는다 → 룩을 고른다 → 부위마다 "여기에 이렇게 그리세요" 테두리를 보여준다 → 그리고 나서 확인받기를 누르면 점수를 준다.**

점수를 주려면 컴퓨터가 두 가지를 할 줄 알아야 한다.

1. **얼굴에서 화장이 발린 곳만 골라내기.** 이건 우리가 직접 가르쳐야 하는 유일한 기술이다. 가르치려면 "이 사진에서 여기가 아이라이너, 여기가 볼터치"라고 답이 적힌 사진이 수천 장 필요하다.
2. **맨얼굴과 화장한 얼굴의 색 차이를 재기.** 이건 계산으로 하지만, 그 계산이 진짜 사람 얼굴에서도 맞는지 확인할 사진이 필요하다.

그래서 필요한 건 크게 세 가지다.

- **연습 문제** — 컴퓨터를 가르칠 사진(학습용)
- **시험지** — 우리가 만든 게 진짜 얼굴에서도 되는지 확인할 사진(검증용)
- **화면에 보여줄 것** — 룩 사진, 문구, 제품 이름(콘텐츠)

그리고 중요한 규칙 하나. **인터넷에 있는 얼굴 사진은 대부분 "연구할 때만 써도 된다"는 조건이 붙어 있다.** 그런 사진은 시험지로는 써도 되지만, 컴퓨터를 가르치는 데 쓰거나 앱 화면에 띄우면 안 된다. 그래서 학습용과 화면용은 우리가 직접 찍거나, 컴퓨터가 만든 가짜 얼굴을 쓴다.

## 2. 우리가 직접 찍어야 하는 것 (가장 급함)

지금까지 채점 기능은 **컴퓨터가 그린 가짜 화장**으로만 시험을 봤다. 진짜 사람이 진짜로 그린 화장 사진이 없으면 채점이 실제로 맞는지 알 수 없다. 인터넷 어디에도 "아이라이너·섀도우·볼터치가 어디 발렸는지" 답이 적힌 사진은 없다. 그래서 이건 우리가 만들어야 한다.

### 촬영 세션 한 번으로 다 해결한다

| 항목 | 내용 |
|---|---|
| 누가 | 팀원 6명 + 지인 14명 = 20명 |
| 몇 장 | 한 사람당 10장. 1차 200장, 나중에 2차 500장 |
| 무엇으로 | 폰 앞카메라. 얼굴이 화면 폭의 60% 이상 차게 |
| 어떻게 | 같은 자리에서 **맨얼굴 → 눈썹 → 아이라이너 → 섀도우 → 립 → 볼터치** 순서로 한 단계 그릴 때마다 한 장씩 |
| 조명 | 창가, 실내등, 어두운 곳 3가지 |
| 각도 | 정면, 좌우로 조금(15°), 좌우로 더(30°) |
| 꼭 | **사진 사용 동의서**에 서명 받기 (발표·학습·앱 화면에 쓴다고 적힌 것) |

이 사진 한 묶음으로 한 번에 얻는 것:

- **채점 시험지**: 진짜 화장 사진으로 채점이 맞는지 확인
- **연습 문제의 정답**: 한 단계 그리기 전과 후 사진을 비교하면 "이번에 발린 곳"이 자동으로 나온다. 그걸 초안 삼아 사람이 조금만 고치면 정답 사진이 된다(장당 5분, 200장이면 6명이 3시간씩)
- **조명이 바뀌어도 되는지**: 조명 3가지로 찍었으니까
- **고개를 돌려도 되는지**: 각도 3가지로 찍었으니까
- **얼굴형 답지**: 이 사진 50장에 "이 사람은 둥근형, 이 사람은 계란형"을 우리가 적으면 얼굴형 판단이 맞는지 볼 수 있다

💡 왜 인터넷 사진으로 안 되나: 화장 위치가 표시된 공개 사진이 없고, 있는 것도 연구용이라 학습에 못 쓴다. 컴퓨터가 그린 가짜 화장으로만 가르친 모델을 실제 사진에 돌려 봤더니 눈썹을 거의 못 찾았다(맞은 비율 6~11%). 진짜 사진이 꼭 필요하다는 게 숫자로 확인됐다.

## 3. 인터넷에서 바로 받아오는 것

### 3-1. 가짜 맨얼굴 사진 (SFHQ)

- **이게 뭔데**: 컴퓨터가 만든, 세상에 없는 사람 얼굴 사진 42만 장. 큼직하고(1024×1024) 선명하다. 실존 인물이 아니라 초상권 걱정이 없다.
- **왜 필요한데**: 우리한테는 이미 "맨얼굴 사진 위에 컴퓨터가 화장을 그려 넣으면서 정답도 같이 만드는 도구"가 있다(jeakeun이 만든 `poc/synth`). 그 도구에 넣을 **깨끗한 맨얼굴 도화지**가 이 사진이다. 지금 갖고 있는 샘플 20장은 너무 작아서 못 쓴다.
- **어떻게 받나**: Kaggle 계정 만들고 → 설정에서 API 토큰 받아 `kaggle.json`을 내 컴퓨터 `.kaggle` 폴더에 두고 → 아래 한 줄. 4부분으로 나뉘어 있는데 1부분만 먼저.
  ```
  pip install kaggle
  kaggle datasets download -d selfishgene/synthetic-faces-high-quality-sfhq-part-1 -p C:\data\danghwaeung\sfhq --unzip
  ```
  링크: https://www.kaggle.com/datasets/selfishgene/synthetic-faces-high-quality-sfhq-part-1 · 설명: https://github.com/SelfishGene/SFHQ-dataset
- **받고 나서**: 화장한 얼굴도 섞여 있다. 같이 딸려 오는 "검색용 벡터"로 "no makeup"을 검색해 화장 없는 얼굴만 골라낸다.
- **안 되면**:
  1. **SFHQ-T2I** — 같은 사람이 다른 방식으로 만든 가짜 얼굴 12만 장. https://huggingface.co/datasets/bitmind/SyntheticFacesHQ
  2. **FairFace** — 진짜 사람 사진 10만 장, 상업 사용 가능. 다만 작게 잘라 놓은 사진이라 화질이 낮다. 피부색·조명 통계용. https://github.com/joojs/fairface
  3. **Generated Photos 구매** — 가짜 인물 사진을 파는 곳. 화장 없는 얼굴을 골라 살 수 있고 250장 넘으면 장당 2.5달러. 룩 사진(아래 5번)에도 쓸 수 있다. https://generated.photos/pricing
- **쓰면 안 되는 것**: FFHQ, CelebA-HQ, Microsoft FaceSynthetics — 유명하지만 전부 "연구용만". 학습에 쓰면 우리 모델까지 상업 금지가 된다.

### 3-2. 얼굴 부위가 색칠된 셀피 (EasyPortrait)

- **이게 뭔데**: 폰으로 찍은 셀피에 "여기는 왼쪽 눈썹, 여기는 오른쪽 눈, 여기는 입술" 하고 픽셀마다 색칠해 둔 정답 사진 2만 장.
- **왜 필요한데**: 우리 모델에게 화장 찾기를 가르치기 전에 **"얼굴 부위 찾기" 기본기**를 먼저 가르쳐야 하는데, 그 교재로 쓴다. 상업 사용이 가능한 계열 라이선스라 학습에 넣어도 된다. 그리고 우리 모델이 부위를 얼마나 정확히 오리는지 채점하는 시험지로도 쓴다.
- **믿을 만한가**: jeakeun이 200장을 실제로 우리 파이프라인에 돌려 봤다. 얼굴 검출 100%, 우리 앱이 요구하는 해상도를 93%가 만족했다.
- **어떻게 받나**:
  ```
  pip install -U huggingface_hub
  hf auth login
  hf download gofixyourself/EasyPortrait --repo-type dataset --local-dir C:\data\danghwaeung\easyportrait
  ```
  링크: https://huggingface.co/datasets/gofixyourself/EasyPortrait
- **안 되면**: LaPa(2.2만 장) → CelebAMask-HQ(3만 장, Kaggle 미러 https://www.kaggle.com/datasets/ipythonx/celebamaskhq). 둘 다 "연구용만"이라 시험지로만.

### 3-3. 눈 부위가 색칠된 사진 (Periorbital)

- **이게 뭔데**: 눈 주변만 잘라낸 사진 2,842장에 홍채·흰자·눈꺼풀·눈썹을 사람이 손으로 색칠한 것. 상업 사용 가능(CC BY 4.0).
- **왜 필요한데**: 눈썹·눈꺼풀을 우리가 얼마나 정확히 찾는지 채점하는 시험지. 이걸로 "MediaPipe가 잡는 홍채가 실제보다 12% 작다"는 걸 확인했고, 그래서 우리가 홍채 크기로 mm를 재는 방식을 버렸다.
- **어떻게 받나**: Zenodo·GitHub `periorbital-dataset` 검색. 눈만 있어서 얼굴 검출은 안 된다.

### 3-4. 화장 전·후 사진 쌍 (FFHQ-Makeup) — 참고만

- **이게 뭔데**: 같은 얼굴의 맨얼굴 1장 + 화장 5가지 = 10만 장. 사진이 정확히 겹쳐져 있다.
- **왜 필요한데**: "화장하면 색이 보통 얼마나 변하나"를 통계로 내서 우리 기준값의 출발점으로 삼는다. 화장은 AI가 입힌 것이고 "연구용만"이라 학습·화면에는 못 쓴다.
- **어떻게 받나**: `hf download cyberagent/FFHQ-Makeup --repo-type dataset`
- 비슷한 것(MT, BeautyFace, Makeup-Wild)도 전부 연구용. CPM은 링크가 죽었다.

### 3-5. 얼굴형이 적힌 사진 (Kaggle Face Shape) — 참고만

- **이게 뭔데**: 서양 연예인 사진 5,000장에 "하트형·긴형·계란형·둥근형·각진형"이 적힌 것.
- **왜 참고만인가**: 누가 어떻게 적었는지 근거가 없다. 논문에서도 이런 방식의 정확도가 36~65%밖에 안 된다. 그래서 **얼굴형 답지는 2번 촬영 사진 50장에 우리가 직접 적는 게 1순위**다.
- 링크: https://www.kaggle.com/datasets/niten19/face-shape-dataset

## 4. 신청해 두고 기다리는 것 (AI Hub, 정부 데이터)

AI Hub는 정부가 공개하는 한국인 데이터 사이트다. **회원가입(한국인 휴대폰 인증) → 데이터 페이지에서 "다운로드" → 신청서 제출 → 승인 → 다운로드.** 승인에 시간이 걸리니 **이번 주에 세 개를 한꺼번에 신청**해 둔다. 조건: 학습에는 써도 되지만 **앱 화면에 띄우거나 남에게 넘기면 안 된다.**

| 데이터 | 이게 뭔데 | 왜 필요한데 |
|---|---|---|
| **한국인 안면 이미지** | 한국인 1,000명을 스튜디오에서 조명 30가지 × 고개 각도 20가지로 찍은 사진 | 우리는 집 조명 3가지밖에 못 찍는다. 조명이 바뀌어도 채점이 흔들리지 않는지, 고개를 돌려도 추적이 되는지 넓게 시험 |
| **글로벌 다인종 피부색** | 2,525명의 이마·볼·목 피부색을 **기계로 정확히 잰 값** + 조명 4가지 | 우리가 사진에서 계산한 "색 차이"가 진짜 측정값과 맞는지 대조하는 저울 |
| **한국인 피부상태 측정** | 한국인 1.4만 장을 스마트폰 포함 3기기로 찍고 이마·볼·입술 위치 표시 | 한국인 피부색이 보통 어느 범위인지 → 채점 기준선 |

- 한국인 안면 이미지: https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=83
- 신청서 양식: https://aihub.or.kr/web-nas/aihub21/files/public/FAQ%20%EC%8B%A0%EA%B7%9C%EB%93%B1%EB%A1%9D/%EC%9D%B8%EA%B3%B5%EC%A7%80%EB%8A%A5%20%ED%95%99%EC%8A%B5%EC%9A%A9%20%EB%8D%B0%EC%9D%B4%ED%84%B0%20%EC%82%AC%EC%9A%A9%EC%8B%A0%EC%B2%AD%EC%84%9C.docx
- 이용 규칙: https://www.aihub.or.kr/intrcn/guid/usagepolicy.do?currMenu=151&topMenu=105
- 전체는 수백 GB라 다 받지 말고, 대용량 도구(aihubshell, Windows는 WSL 필요)로 조명·각도 일부만 받는다. 안내: https://www.aihub.or.kr/devsport/apishell/list.do
- 승인이 늦으면 조명·각도 시험은 2번 촬영 사진으로만 간다.

## 5. 우리가 만들어야 하는 것 (화면에 보이는 것)

| 무엇 | 왜 | 상태 |
|---|---|---|
| **룩 사진 10장** | 앱에서 "이 룩으로 할래요" 고를 때 보이는 얼굴. 사용자 눈에 보이니 연구용 사진은 절대 못 쓰고, 무료 스톡 사진도 초상권 문제가 있다 | **아직 못 정함.** 팀원 촬영(동의서) / 컴퓨터로 생성 / Generated Photos 구매 중 하나로 결정해야 다음 단계가 풀린다 |
| 룩마다 "어떻게 그리라"는 값과 제품 목록 | 테두리 모양과 채점 기준이 여기서 나온다 | 우리가 직접 만들 예정. 시점은 나중에 |
| 근거 문장 55개 + 얼굴형 멘트 5개 | "눈꼬리를 살짝 올려 짧게 빼세요" 같은 한 줄 | 초안 있음, 룩 값과 함께 확정 |
| 결과 한 줄 평 문장 40개 | "오른쪽 꼬리가 조금 위로 갔어요" 같은 것 | 초안 있음 |
| 촬영 안내 문구 15개 | "조금만 정면으로" 같은 것 | 있음 |
| 쉐딩·하이라이트 규칙의 출처 | "둥근 얼굴은 턱선에 쉐딩" 같은 규칙을 어느 교재에서 가져왔는지 | 아직 없음. 화장 교재·브랜드 가이드 3곳 이상에서 공통점 찾기 |

## 6. 나중에 정하기로 한 것

- 채점 기준값("꼬리가 이만큼 벗어나면 틀림", "이 정도 진하면 적당") — 실험으로 재지 않고 우리가 정한다. 지금은 임시값.
- 전문가 평가(화장 전문가가 사진 30~50장에 점수) — 하면 좋지만 필수는 아님.
- 설문 100명, 사용자 실험 10명 — 일정표대로 1주차·4주차.

## 7. 쓰면 안 되는 것과 이유 (한 번만 읽어 두기)

| 하려는 것 | 써도 되는 사진 | 쓰면 안 되는 사진 |
|---|---|---|
| 컴퓨터 가르치기(학습) | 가짜 얼굴(SFHQ), FairFace, EasyPortrait, **우리가 찍은 사진**, 구매한 사진, AI Hub | FFHQ, CelebA, LaPa, FFHQ-Makeup 등 "연구용만" 전부. 학습에 넣으면 우리 모델도 상업 금지가 된다 |
| 앱 화면에 띄우기 | 우리가 찍은 사진(동의서), 컴퓨터 생성, 구매한 사진 | 연구용 전부, AI Hub, 무료 스톡 사진(초상권 확인 안 됨) |
