# nudy — 문서 색인

서비스 이름 **nudy** (전 당화응, 2026-09-29). 새로운 화장을 배우고 싶은 사람을 위한 단계별 화장 코치. 플랫폼은 모바일 웹.

2026-10-06 에 흐름이 바뀌었다. **지금 흐름**은 아래 첫 표의 문서만 보면 된다. 바뀌기 전 흐름(4장 촬영 · 화장 10종 · AR · 부위별 점수)의 문서는 지우지 않고 [`archive/`](archive/README.md) 로 옮겼다 (2026-10-11).

## 지금 흐름
