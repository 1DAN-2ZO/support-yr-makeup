## 확정 화면 흐름 (새 흐름, 2026-10-06)

동의 → 1 맨얼굴 촬영(정면 눈 뜬 장 하나) → 2 참고 사진 올리기(못 쓰는 사진이면 다시) → 3 정답사진(참고 화장을 내 맨얼굴에) → 4 부위별 가이드(정답사진 조각 + 점 · 선, 부위마다) → 5 시도사진(다시 찍기 가능) → 6 피드백(점수 없이 부위별로 잘함 · 덜 그림 · 넘침) → 7 폰에 저장 · 공유 → 끝내기(세션 삭제)

그림: `flowchart-new-flow.svg`. 자세한 내용과 팀 나눔은 `service-definition-v6.md` 맨 위.
