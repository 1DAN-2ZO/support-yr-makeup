## v6 확정 화면 흐름
1 촬영 4장 → 2 룩 얹어보기(실시간 트래킹, 룩 10개, 제품 안내) → 2-b 전체 완성 예상 한 장 → [3 부위 완성본 → 4 실시간 테두리(눈·눈썹 가로) → 확인받기 → 5 점수·테두리·한 줄 평 → 통과 / 재시도(3으로) / 건너뛰기] × 부위 → 7 부위 점수·합산 + 쌩얼 vs 내 화장 → 끝(세션 데이터 삭제)

## 아직 확정 안 된 것
- (화면 1 확정: 동의 세션마다 · 자동 촬영만 · 틀린 장만 다시 찍기)
- (확정: **얼굴형 개인화는 쉐딩·하이라이트 가이드에만.** 나머지 부위·룩은 그대로. 쉐딩·하이라이트 완성본에 얼굴형 멘트 한 줄)
- (확정: **룩 템플릿 10개에 쉐딩·하이라이트 없음.** 쉐딩·하이라이트는 얼굴형 규칙으로 만드는 고정 마지막 단계, 완성본은 폰에서 규칙 합성)
- (화면 2 확정: 로딩 중 표시 · 룩 10개 · 제품 목록 접기 없음 · 확정 뒤 전체 완성 예상 한 장)
- (화면 3 확정: 완성본은 그 부위만 · 근거 숫자 없음 · 눈·눈썹 단계는 3·4·5 모두 가로, 세로 부위로 돌아올 때 세로 안내) 
- (화면 4 확정: 테두리만 · 확인받기 즉시 촬영 · 자리 비움 안내 없음 · 건너뛰기는 결과 화면에만. 품질 게이트는 안 맞는 조건 하나만 한 줄 · 진행 칩은 누르면 그 부위로 이동) 
- (화면 5 확정: 어긋난 곳 표시 없이 테두리만 · "다음" 버튼(점수 낮아도 가능, 자동 통과 없음) · 재시도 · 건너뛰기. 쉐딩·하이라이트는 항상 "확인만"(점수 없음) + "확인하고 넘어가세요" + 다음, 다른 부위 측정 불가도 같은 표시)
