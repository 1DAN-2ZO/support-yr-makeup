# 피드백(화면 6)이 받는 그림의 조건 — 정답사진 · 옮긴 그림을 만드는 쪽에게

2026-10-07 · ③ 채점/피드백 (덕현) → 정답사진을 만드는 쪽 (① · ②)

화면 6 의 피드백은 시도사진을 정답사진과 견줘 부위별 문장을 낸다. 피드백 코드는 **어떤 모델로 만들었는지가 아니라, 받는 그림이 아래 조건을 지키는지**에 기댄다. 모델을 가볍게 하거나 설정을 바꾸는 것(최적화)은 만드는 쪽이 정하고, 그 결과가 이 조건과 아래 시험을 통과하면 된다. 누가 만들든 같은 형식으로 받는다.

조건마다 근거가 된 실험은 브랜치 `score-shape` 의 `eval/samples/shape/README.md` 에 있다 (실험 26 · 28 · 30 · 39~43).

## 1. 주고받는 것

**앱 → 만드는 쪽**

| 무엇 | 언제 |
|---|---|
| 맨얼굴 (정면, 눈 뜬 장) + 참고 사진 | 정답사진을 만들 때 (화면 3) |
| 맨얼굴 (같은 장) + 시도사진 (정면, 눈 뜬 장 하나) | 피드백을 낼 때 (화면 6) |

**만드는 쪽 → 앱**

| 무엇 | 쓰는 곳 |
|---|---|
| **정답사진** — 참고 사진의 화장을 맨얼굴에 옮긴 그림 | 입술 · 섀도우 · 눈썹 · (볼) 견주기, 화면에 보여 주기 |
| **옮긴 그림** — 시도사진의 화장을 **같은 방법으로** 같은 맨얼굴에 옮긴 그림 | 라이너 꼬리 길이 (정답사진의 꼬리와 견준다) |

옮긴 그림이 없어도 입술 · 섀도우 · 눈썹은 판정한다. 라이너만 "이번에는 볼 수 없었어요"가 된다.

## 2. 받는 그림이 지킬 조건

정답사진과 옮긴 그림 모두에 해당한다.

1. **맨얼굴과 같은 크기 · 같은 자리로 겹친다.** 같은 칸이 얼굴의 같은 자리여야 한다. 모델 출력 그대로는 안 된다 — 얼굴이 눈 폭의 0.5~6% 밀리고, 눈 크기 · 표정 · 피부 톤까지 바뀐다
2. **모델 그림을 맨얼굴의 얼굴 점에 맞춰 편 뒤, 화장 부위(눈 · 눈썹 · 입술 · 볼)만 맨얼굴에 붙인다.** 그 밖은 맨얼굴 그대로
3. **그림을 그대로 붙인다.** 색 차이만 떠서 더하면 2~3px 굵기의 라이너 꼬리가 사라진다
4. **정답사진과 옮긴 그림은 같은 모델 · 같은 설정 · 같은 처리로 만든다.** 다르면 진하기 · 꼬리 길이를 견줄 수 없다
5. **얼굴이 작아지지 않게 한다 — 줄이기 전에 얼굴을 먼저 자른다.** 촬영 화면의 사진은 2160 x 3840 이고 얼굴은 그 일부다. 긴 변 1600 으로 먼저 줄이면 눈 폭이 52px 이 되고, 그 결과에서는 꼬리를 못 쟀다 (눈 10개 중 2개 틀림, 실험 43). 눈 폭 144px 로 들어간 묶음에서는 쟀다. **하한 숫자는 아직 못 정했다** — 얼굴만 잘라 다시 돌린 결과를 보고 채운다
6. **잘라서 만들었으면 자른 자리를 같이 준다** (맨얼굴 원본에서 왼쪽 위 x · y, 가로 · 세로, 줄인 배율). 앱이 원본 맨얼굴에 다시 겹칠 수 있어야 한다
7. **정답사진을 만들 때 쓴 맨얼굴이 앱의 맨얼굴과 다른 사진이면 그 맨얼굴도 같이 준다.** 같은 사람이어도 다른 촬영이면 윤곽이 10% 어긋났다 (실험 39 · 40). 같은 사진으로 만들면 필요 없다 — 이쪽이 좋다
8. 손실 없는 형식(PNG)으로. 다시 압축하면 가는 선이 먼저 흐려진다

## 3. 통과해야 하는 시험

모델 · 설정 · 처리(자르기, 가리기, 붙이기, 가볍게 하기, 단계 수, 출력 크기) 중 하나라도 바뀌면 다시 돌린다. **실제로 서비스할 기계의 설정으로** 돌린 결과여야 한다.

③ 이 주는 시험 사진 묶음(맨얼굴 1장 + 참고 사진 5장, 6번 실행)을 돌리고 결과를 돌려주면 ③ 이 같은 방법으로 잰다.

| 참고 사진 | 봐야 하는 것 |
|---|---|
| 화장 없는 사진 | 화장을 지어내지 않는다 |
| 섀도우만 (라이너 없음) | 라이너 꼬리를 지어내지 않는다 |
| 라이너를 한쪽 눈에만 | 꼬리가 그 눈에만 있다 |
| 라이너 양쪽 — 시작값 2개 | 두 눈 다 있다. 두 장의 길이 · 방향이 비슷하다 |
| 립까지 완성 | 립이 옮겨진다 |

FLUX.2 klein 4B 원본판(4단계, 긴 변 1024)은 이 다섯 가지를 지켰다. 시작값에 따른 폭은 진하기 0.6~1.1배 · 꼬리 길이 눈 폭의 1~4%p 였다 — 판정 기준은 이 폭보다 촘촘할 수 없으므로, 폭이 더 커지는 설정이면 알려 달라.

**돌려줄 것**

- 모델 출력 원본 6장 (손대지 않은 것)
- 조건 2 · 3 대로 만든 판 6장 (맨얼굴과 같은 크기)
- 모델에 실제로 들어간 그림 (자른 맨얼굴 · 손질한 참고 사진)과 그 크기
- 설정 기록: 모델과 가볍게 한 방식 · 단계 수 · 출력 크기 · 지시문 · 참고 사진 손질 · 붙이는 방식 · 한 장 걸린 시간 · 돌린 기계 · 맨얼굴과 참고 사진의 눈 폭(px)

**시험 사진은 저장소에 없다.** 팀원의 얼굴 사진이라 ③ 이 따로 전달한다. 돌리는 기계 안에서만 쓰고(외부 서비스 · 저장소 · 커밋 금지), 결과를 넘긴 뒤 사진과 결과를 지운다.

## 4. 피드백이 내보내는 것

부위(눈썹 · 섀도우 · 라이너 · 볼 · 입술)마다 문장 하나 + 덧붙임 최대 하나 + 고치는 방법(방향만). 점수 · 숫자 없음. 화면 구성은 #318.

## 5. 아직 정하지 않은 것

- 조건 5 의 눈 폭 하한 숫자
- 정답사진 · 옮긴 그림을 앱 안에서 넘겨받는 자리 (함수 · 주소)
- 옮긴 그림을 만드는 데 걸리는 시간(한 장 7~9초)을 화면 6 에서 어떻게 기다리게 할지
- 시도사진이 서버로 가는 것을 서비스 정의서 · 동의 문구에 넣기
- 볼: 부위 다각형의 평균으로는 묽게 읽혀 지금은 판정하지 않는다. 칠한 자리를 따로 받으면 다시 본다
