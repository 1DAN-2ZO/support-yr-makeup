## 1주차에 시작할 것 (★ 6개)

1. **A-2·A-3·E-1·E-2를 한 번의 촬영 세션으로** — 팀원 3~5명이 같은 자리에서: 맨얼굴 4장 → 부위별 덧바름 1·2·3회 → 조명 바꿔 재촬영. 촬영 프로토콜(거리·조명·순서)을 먼저 문서로.
2. **AI Hub 한국인 안면 이미지 신청** (승인 대기 시간 때문에 먼저).
3. **D-1 룩 참조 이미지 방법 결정** (자체 촬영 vs 생성) → D-2 룩 값 확정과 함께.
4. **C-1**: 위 참조 사진이 생기면 서버 화장 전이를 우리 맨얼굴로 돌려 정체성 유지 확인.

## 라이선스 한 줄 규칙
- 화면에 띄우는 사진(D-1)과 학습에 넣는 사진(B)은 **비상업 데이터셋 불가**. 평가·참고(C, B-4)는 가능.
- 자체 촬영은 **서면 동의서**(사용 범위: 발표·학습·앱 화면) 필수. 양식을 1주차에 만든다.
