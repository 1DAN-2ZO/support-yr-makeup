# 폰 실기기 측정·점검 계획 (2026-09-30, 모듈 ①)

1-4 조명 변동 폭(사람 2·3), 앞머리·안경·고개 숙임·어두운 곳 가림, 1-12 아이폰 칸을 **한 번에** 끝내는 계획이다.
결과로 가정값(밝기 ±12, 색 6, 앞머리 darkDL 20·minSkin 0.25, 정면 pitch, 어두울 때 가림 40)을 확정한다.

## ELI5 — 쉽게 말하면

- 사진 찍기 규칙에 쓰는 숫자들이 아직 "대충 정한 값"이에요. 두 사람이 폰으로 조명을 바꿔 가며 찍어 보면 진짜 값이 나와요.
- 한 명은 안드로이드, 한 명은 아이폰으로 찍고, 아이폰은 앱을 처음부터 끝까지 한 번 써 봐요.
- 집 PC 가 서버 역할을 하고, 찍은 결과(숫자만, 사진 없음)는 집 PC 에 자동으로 모여요.

| 역할 | 장비 | 할 일 |
|---|---|---|
| 서버 담당 (①) | 집 PC (RTX 4080) | 앱 서버(클로드가 켬, 127.0.0.1) + Cloudflare 터널(사람이 PowerShell 에서 켬) → 주소를 두 폰에 공유. 회차마다 "누가·무슨 조건" 을 채팅으로 남기면 클로드가 `client/.probe` 결과와 짝짓는다 |
| Android 담당 (사람 2) | Android 폰 · Chrome | 아래 측정 |
| iPhone 담당 (사람 3) | iPhone · Safari | 아래 측정 + 앱 전체 흐름 점검 |

.\cloudflared.exe tunnel --no-tls-verify --url https://127.0.0.1:5173

| 2 | 앞머리·안경 | 넘김 / 반쯤 내림 / 다 내림 / 안경 씀 | 4 | 앞머리 `darkDL` 20 · `minSkin` 0.25, 안경 판정 여부 |
