## 1. 정의

서비스 이름: **당화응**. 플랫폼은 **지금은 모바일 웹(브라우저)**, 안드로이드 앱은 이후 단계.

**당화응은 매 세션 사용자의 맨얼굴을 찍어 오늘의 기준을 만들고, 원하는 화장을 얼굴에 얹어 보고 고르게 하며, 그 화장에 어떤 제품이 쓰이고 "어디에 어떻게" 해야 하는지 부위별로 확대해 보여주고, 한 부위씩 화장한 결과를 사용자가 원할 때 확인하고 넘어가게 하는 단계별 화장 교정 서비스다.**

가상으로 화장을 입혀 보는 데서 끝나는 서비스가 아니다. 실제 화장을 한 부위씩 제대로 하게 만드는 서비스다.

## 2. 핵심 컨셉

**"운동 코치가 동작 하나씩 잡아주듯, 화장을 부위 하나씩 잡아준다."**

```
맨얼굴 촬영 (오늘의 기준) → 화장 골라 얼굴에 얹어보기 → 룩 확정 (쓰이는 제품 확인)
→ 전체 완성 예상 한 장 → [부위 완성본 → 실시간 테두리 → 거울에서 화장 → 돌아와서 확인받기 → 다음] × 부위 수 → 전체 리뷰
```

한 번에 다 그리고 한 번에 채점하지 않는다. 눈썹이 통과해야 아이라이너로 넘어간다. 채점은 사용자가 "확인받기"를 눌렀을 때만 한다.

## 3. 누구에게

**새로운 화장을 배우고 싶은 사람.** 처음 색조를 시작하는 사람, 안 해 본 룩을 익히려는 사람, 유튜브를 따라 해도 내 얼굴에서는 안 되는 사람. 성별·연령 제한 없음.

> 근거 수치: 남성 시장 수치(1.2조, 후기 부족 46.6%)는 보조 근거. 1주차 설문을 "새 화장을 시도하다 실패한 경험"으로 전 성별에 실시.

## 4. 무엇이 다른가

| | 기존 서비스 | 당화응 |
|---|---|---|
| 얼굴을 어떻게 아나 | 사진 한 장, 한 번 등록 | **매 세션 맨얼굴 4장(정면 눈 뜸·눈 감음, 좌·우 45°)으로 만든 오늘의 기준(색·척도·조명·눈꺼풀·옆 볼 기준)** |
| 룩 선택 | 완성 모습만 미리보기 | **내 얼굴에 실시간으로 얹어 보고, 쓰이는 제품 종류까지 보고 고름** |
| 무엇을 보여주나 | 완성 모습 미리보기 | **부위별 확대 화면에 그리는 위치·방향** |
| 진행 방식 | 한 번에 전체 | **한 부위씩 확인 후 다음 단계** |
| 화장 뒤에 뭘 하나 | 없음, 또는 정성 평가 | **이탈 거리·좌우 대칭·톤 차이를 숫자로, 부위 점수 + 합산 점수** |

## 5. 핵심 가치

1. **오늘의 내 얼굴 기준** — 세션마다 맨얼굴을 찍어 색 기준·mm 척도·조명 참조를 새로 만든다.
2. **얹어 보고 고른다** — 룩을 내 얼굴에 입힌 채 고개를 돌려 보며 비교한다. 쓰이는 제품 종류가 함께 나온다. 룩은 조정 없이 그대로다.
3. **완성본을 먼저 보고, 그릴 자리를 실시간으로 본다** — 부위마다 다 되면 어떤 모습인지 완성본을 먼저 보여주고, 다음 화면에서 그릴 자리 테두리가 얼굴을 따라 실시간으로 뜬다. 눈썹·눈은 양쪽을 한 화면에 담고, 이때만 "폰을 가로로 돌리세요" 안내가 뜬다.
6. **어느 단계든 골라서 돌아간다** — 진행 칩에서 부위를 누르면 그 단계로 돌아가 가이드를 다시 보고 다시 확인받을 수 있다.
4. **내가 원할 때 확인한다** — 거울에서 화장하고 돌아오면 가이드 화면이 그대로 있고, "확인받기"를 눌러야만 채점한다.
5. **정직한 점수** — 사용자에게는 점수와 한 줄 평만 보여준다. mm·각도 같은 숫자는 내부 계산에만 쓴다. 절대값을 못 재는 항목은 점수 없이 "확인만".

## 6. 서비스 구성

| 구성 | 역할 | 언제 |
|---|---|---|
| **맨얼굴 촬영** | 세션마다 서버 처리 동의 → 정면(눈 뜸·눈 감음) + 좌·우 45°, 4장 **자동 촬영만**(수동 셔터 없음). 틀린 장만 다시 찍기 가능. 랜드마크·홍채 척도·맨얼굴 색·조명 참조·옆 볼 기준 | 세션 시작, 1분 |
| **얹어보기** | 룩 10개. 서버 생성이 끝날 때까지 "로딩 중" 표시, 끝나면 화장 레이어를 내려받아 **카메라 프리뷰의 얼굴을 실시간으로 따라가며 표시**. **쓰이는 제품 목록**(접기 없음) | 룩 고를 때 |
| **전체 완성 예상** | "이 룩으로 시작" 뒤 한 장. 내 정면 사진에 룩 전체가 입혀진 렌더링 + "시작" | 룩 확정 직후 |
| **부위 코칭** | 룩을 부위별로 분해 → 완성본 보기(화면 3) → 실시간 테두리(화면 4, 눈썹·눈은 양쪽·가로) + 필요한 제품 한 줄 → 거울에서 화장 → 돌아와서 확인받기 → 부위 결과(화면 5: 점수·테두리 겹침·한 줄 평) → 다음. 진행 칩으로 어느 단계든 선택해 돌아가기 | 부위마다 |
| **전체 리뷰** | 부위별 점수(못 잰 부위는 "확인만") + 한 줄 평 + 합산 숫자, 쌩얼 vs 내 화장 나란히 두 장. "결과 저장"(비교 이미지 갤러리 저장, 선택) / "끝내기"(세션 삭제) | 세션 끝 |

## 7. 부위 코칭 한 단계

```
[완성본]  이 부위만 입힌 정지 이미지(다른 부위는 맨얼굴)로 어떤 모습인지 먼저 보여줌 (화면 3). 근거는 숫자 없이 말로
[실시간]  그릴 자리 테두리가 얼굴을 따라 뜸, 근거 한 줄, "지금 필요한 것: 핑크 파우더 블러셔 + 브러시" (화면 4)
          눈썹·아이라이너·섀도우는 완성본·실시간·결과 모두 가로 화면 → 단계 진입 때 "폰을 가로로 돌리세요",
          입술·볼·쉐딩 등 세로 부위로 돌아올 때 "폰을 세로로 돌리세요" 안내
[화장]    사용자가 거울로 이동. 폰은 그대로. (앱 종료돼도 세션 복원)
[돌아옴]  가이드 화면이 그대로 있음(자리 비움 안내 문구 없음). 얼굴이 다시 잡히면 테두리가 다시 붙고 "확인받기" 버튼만 활성. 누르면 즉시 촬영
[확인]    버튼은 얼굴 추적 품질(정면성·양쪽 눈·손 없음·선명도·밝기)이 맞을 때만 활성.
          누른 순간부터 안정 3~5프레임 평균으로 채점하고 결과 화면으로 넘어감
[결과]    점수 + 내 화장 위에 가이드 테두리 겹침 + 한 줄 평 (화면 5). mm·각도 숫자는 안 보여줌
[판정]    "다음" (점수 낮아도 가능, 이 점수로 확정) / 재시도 → 완성본(화면 3)부터 / 건너뛰기 (합산 제외). 자동 통과 없음
[이동]    상단 진행 칩에서 아무 단계나 눌러 돌아가기. 이미 통과한 부위도 다시 확인받으면 최신 결과로 갱신
```

기본 순서(입문 데일리): 눈썹 → 아이라이너 → 섀도우 → 입술 → 볼터치 (여기까지 룩 템플릿) → 쉐딩·하이라이트 (룩과 무관, 얼굴형 규칙). 변경 가능.

## 8. 한 사람의 세션

> 스모키 아이를 처음 해 보려는 24세. 앱을 켠다. 안내대로 정면에서 눈을 감았다 뜨고 고개를 좌우로 돌리며 4장이 자동으로 찍힌다. "오늘 기준 등록 완료"가 뜬다.
>
> 룩 목록이 나온다. "데일리 정돈", "면접", "스모키", "음영 강조". 하나씩 누르면 카메라 속 내 얼굴 위에 그 화장이 얹혀 고개를 돌려도 따라온다. 스모키를 고르니 "이 룩에 쓰인 것: 다크 브라운 섀도우(매트), 블랙 젤 라이너, 핑크 파우더 블러셔, MLBB 립" 목록이 나온다. 스모키를 확정하자 내 얼굴에 스모키가 다 된 모습 한 장이 뜨고, "시작"을 누른다.
>
> 첫 부위는 눈썹. "폰을 가로로 돌리세요" 안내가 뜨고, 양쪽 눈썹이 한 화면에 크게 나오며 가이드가 얹힌다. "지금 필요한 것: 브라운 아이브로 펜슬". 폰을 두고 거울로 가서 그린다. 중간에 돌아와 가이드를 한 번 더 보고 다시 거울로 간다. 다 그리고 돌아와 "확인받기"를 누르니 91점. "다음"을 누른다. 아이라이너. 가로 화면 그대로 양쪽 눈 위에 꼬리 각도가 표시된다. 확인받기를 누르니 82점과 함께 내 눈 위에 가이드 테두리가 겹쳐 보이고 "오른쪽 꼬리가 조금 위로 갔어요. 왼쪽에 맞춰 살짝 내려 그리세요"가 뜬다. 재시도를 누르자 완성본부터 다시 보여주고, 지우고 다시 그린 뒤 89점, "다음". 섀도우 차례에는 눈을 감으라는 안내와 함께 눈꺼풀 위에 방향이 표시된다. 바르고 확인하니 "방향이 잘 맞아요. 왼쪽을 조금만 더". 입술 차례가 되자 "폰을 세로로 돌리세요" 안내가 뜬다. 입술을 지나 볼터치·쉐딩. 중간에 눈썹이 마음에 안 들어 진행 칩에서 눈썹을 눌러 돌아가 다시 확인받고 온다. 확인하니 점수 없이 "확인하고 넘어가세요. 오른쪽이 조금 진해요"가 뜬다. 거울에서 경계를 풀고 "다음". 전체 리뷰에서 부위별 점수와 한 줄 평, 합산 78점이 뜨고, 처음 찍은 쌩얼과 지금 내 화장이 나란히 보인다. "결과 저장"을 눌러 비교 사진을 갤러리에 남기고 "끝내기"를 누른다.

## 9. 범위

**한다**: 매 세션 맨얼굴 촬영, 룩 얹어보기(선택용), 룩별 제품 종류·색 계열 표시, 부위별 확대 가이드, 버튼 방식 확인·다음, 눈썹·아이라이너·입술 정량 채점, 섀도우·볼터치·쉐딩의 유무·방향·세션 내 지수·피부 대비 톤 차이 판정, 부위 점수·합산 점수(화면엔 점수·한 줄 평만), 쌩얼 vs 내 화장 비교, 안드로이드.

**하지 않는다**: 얹어보기를 채점 정답으로 사용, 자동 채점(버튼 없이), 바르는 도중 실시간 채점, 그라데이션 균일도 채점, 뜸·갈라짐 판정, 쉐딩 절대 강도, 다른 사람·다른 폰·다른 날과의 강도 비교, 피부 진단, 브랜드·상품명 추천, 음성 안내, 3D 얼굴 모델, 세션 기록 보관(추이·자주 틀리는 부위는 로드맵), 결과 화면에 mm·각도 숫자 표시.

## 10. 원칙

- **정직한 측정**: 못 재는 건 점수 안 준다. 오차·기준을 같이 표기한다. 못 잰 부위는 합산에서 뺀다.
- **사용자가 촬영 시점을 정한다**: 채점은 "확인받기"를 눌렀을 때만. 언제 분석되는지 사용자가 안다.
- **기기 안에서**: 사진·결과는 세션 동안만 기기 보관, 세션 끝나면 삭제. 서버는 얹어보기 생성·쉐딩 위치 산출에만 쓰고, 처리 후 원본 즉시 삭제.
- **규칙 출처 공개**: 가이드·톤 차이 밴드·제품 목록의 근거를 앱 안에서 볼 수 있다.
- **사용자 수정 우선**: 룩·부위 순서는 사용자가 바꿀 수 있다. 얼굴형 개인화는 쉐딩·하이라이트 위치에만 쓰고, 다른 부위는 룩 그대로.
