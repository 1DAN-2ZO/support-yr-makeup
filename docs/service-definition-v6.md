# 당화응 — 서비스 정의 (v6)

> 2026-09-15 확정본 · 기능 정의서는 `feature-spec-v6.md`, 화면 목업 브리프는 `screen-image-brief-v6.md`

## 0. 한눈에

- **이름** 당화응 · **플랫폼** 지금은 모바일 웹(브라우저), 안드로이드 앱은 이후
- **한 줄** 오늘의 내 맨얼굴을 찍고, 룩을 실시간으로 얹어 보고 고른 뒤, 한 부위씩 "완성본 → 그릴 자리 테두리 → 거울에서 화장 → 확인받기 → 점수·한 줄 평"으로 넘어가는 단계별 화장 코치
- **대상** 새로운 화장을 배우고 싶은 사람. 성별·연령 제한 없음
- **채점 원칙** 사용자가 "확인받기"를 눌렀을 때만 채점. 화면에는 점수와 한 줄 평만, 숫자(mm·각도·%)는 내부용. 못 재는 건 "확인만"

## 1. 정의

**당화응은 매 세션 사용자의 맨얼굴을 찍어 오늘의 기준을 만들고, 원하는 룩을 얼굴에 실시간으로 얹어 보고 고르게 하며, 그 룩에 어떤 제품이 쓰이고 "어디에 어떻게" 해야 하는지 부위별로 보여주고, 한 부위씩 화장한 결과를 사용자가 원할 때 확인하고 넘어가게 하는 단계별 화장 교정 서비스다.**

가상으로 화장을 입혀 보는 데서 끝나는 서비스가 아니다. 실제 화장을 한 부위씩 제대로 하게 만드는 서비스다.

## 2. 핵심 컨셉

**"운동 코치가 동작 하나씩 잡아주듯, 화장을 부위 하나씩 잡아준다."**

```
1 맨얼굴 촬영 4장 → 2 룩 얹어보기(10개, 제품 목록) → 2-b 전체 완성 예상 한 장 → 시작
→ [3 부위 완성본 → 4 실시간 테두리 → 거울에서 화장 → 확인받기 → 5 점수·한 줄 평 → 다음] × 부위
→ 7 전체 리뷰(부위 점수·합산, 쌩얼 vs 내 화장) → 결과 저장(선택) → 끝내기
```

한 번에 다 그리고 한 번에 채점하지 않는다. 한 부위를 확인받고 "다음"을 눌러야 다음 부위로 간다. 채점은 사용자가 "확인받기"를 눌렀을 때만 한다.

## 3. 누구에게

**새로운 화장을 배우고 싶은 사람.** 처음 색조를 시작하는 사람, 안 해 본 룩을 익히려는 사람, 유튜브를 따라 해도 내 얼굴에서는 안 되는 사람.

> 근거 수치: 남성 시장 수치(1.2조, 후기 부족 46.6%)는 보조 근거. 1주차 설문을 "새 화장을 시도하다 실패한 경험"으로 전 성별에 실시.

## 4. 무엇이 다른가

| | 기존 서비스 | 당화응 |
|---|---|---|
| 얼굴을 어떻게 아나 | 사진 한 장, 한 번 등록 | **매 세션 맨얼굴 4장(정면 눈 뜸·눈 감음, 좌·우 45°)으로 만든 오늘의 기준**(색·척도·조명·눈꺼풀·옆 볼) |
| 룩 선택 | 완성 모습 미리보기 | **내 얼굴에 실시간으로 얹어 보고, 쓰이는 제품 종류까지 보고 고름** |
| 무엇을 보여주나 | 완성 모습 | **부위 완성본 → 그릴 자리 테두리(실시간)** |
| 진행 방식 | 한 번에 전체 | **한 부위씩 확인받고 다음** |
| 화장 뒤에 뭘 하나 | 없음, 또는 정성 평가 | **부위 점수 + 한 줄 평 + 합산, 쌩얼 vs 내 화장 비교** |

## 5. 핵심 가치

1. **오늘의 내 얼굴 기준** — 세션마다 맨얼굴을 찍어 색 기준·mm 척도·조명 참조를 새로 만든다.
2. **얹어 보고 고른다** — 룩을 내 얼굴에 입힌 채 고개를 돌려 보며 비교한다. 쓰이는 제품 종류가 함께 나온다. 룩은 조정 없이 그대로다.
3. **완성본을 먼저, 그릴 자리는 실시간으로** — 부위마다 다 되면 어떤 모습인지 먼저 보여주고, 다음 화면에서 그릴 자리 테두리가 얼굴을 따라 뜬다. 눈썹·눈은 양쪽을 한 화면에 담고 이때만 가로 화면.
4. **내가 원할 때 확인한다** — 거울에서 화장하고 돌아오면 화면이 그대로 있고, "확인받기"를 눌러야만 채점한다.
5. **정직한 점수** — 점수와 한 줄 평만 보여준다. mm·각도 같은 숫자는 내부 계산용. 못 재는 항목은 점수 없이 "확인만".
6. **어느 단계든 골라서 돌아간다** — 진행 칩에서 부위를 누르면 그 단계로 돌아가 다시 확인받을 수 있다.

## 6. 서비스 구성

| 구성 | 사용자가 보는 것 | 언제 |
|---|---|---|
| **1 맨얼굴 촬영** | 세션마다 서버 처리 동의(거부하면 이용 불가 안내) → 정면 눈 뜸 → 정면 눈 감음 → 좌 45° → 우 45°, 4장 자동 촬영(셔터 없음). 조건이 안 맞으면 한 줄 안내. 틀린 장만 다시 찍기 | 세션 시작, 1분 |
| **2 룩 얹어보기** | 룩 10개. 서버 생성 전엔 "로딩 중". 카메라 속 내 얼굴에 룩이 실시간으로 얹힘. "이 룩에 쓰인 것" 제품 목록(전부 펼침). "이 룩으로 시작" | 룩 고를 때 |
| **2-b 전체 완성 예상** | 내 정면 사진에 룩 전체가 입혀진 렌더링 한 장 + "시작" | 룩 확정 직후 |
| **3 부위 완성본** | 전체 완성 예상 렌더링(2-b)을 이 부위로 줌한 정지 이미지 + 근거 한 줄(숫자 없음) + "지금 필요한 것" + "그리러 가기" | 부위마다 |
| **4 실시간 테두리** | 그릴 자리 테두리(선만)가 얼굴을 따라 뜸. 품질 게이트 한 줄. "확인받기"(누르면 즉시 촬영) | 부위마다 |
| **5 부위 결과** | 점수 + 내 화장 위 가이드 테두리 겹침 + 한 줄 평. "다음"(점수 낮아도 가능) / 재시도(→3) / 건너뛰기(합산 제외). 쉐딩·하이라이트는 점수 없이 "확인하고 넘어가세요" | 확인받기 직후 |
| **7 전체 리뷰** | 부위별 점수·한 줄 평(못 잰 부위는 "확인만") + 합산 숫자, 쌩얼 vs 내 화장 나란히 두 장. "결과 저장"(갤러리, 선택) / "끝내기"(세션 삭제) | 세션 끝 |

부위 순서(기본): 눈썹 → 아이라이너 → 섀도우 → 입술 → 볼터치 (여기까지 룩 템플릿) → 쉐딩·하이라이트 (룩과 무관, 얼굴형 규칙). 진행 칩(6개)으로 어느 단계든 이동 가능.

## 7. 부위 코칭 한 단계

```
[완성본]  전체 완성 예상 렌더링을 이 부위로 줌한 정지 이미지로 어떤 모습인지 먼저 (화면 3). 근거는 숫자 없이 말로. 쉐딩·하이라이트는 규칙 합성 + 얼굴형 멘트
[실시간]  그릴 자리 테두리(선만)가 얼굴을 따라 뜸. "지금 필요한 것: 핑크 파우더 블러셔 + 브러시" (화면 4)
[방향]    눈썹·아이라이너·섀도우는 3·4·5 모두 가로 → 진입 때 "폰을 가로로 돌리세요". 세로 부위로 돌아올 때 "세로로 돌리세요"
[화장]    사용자가 거울로 이동. 폰은 그대로, 안내 문구 없음. 얼굴이 안 보이면 테두리만 사라짐 (앱 종료돼도 세션 복원)
[돌아옴]  얼굴이 다시 잡히면 테두리가 다시 붙음. 품질 게이트(정면·양쪽 눈·손·선명·밝기) 충족 시 "확인받기" 활성, 미충족이면 안 맞는 것 하나만 한 줄
[확인]    "확인받기" → 즉시 촬영(3~5프레임 평균은 내부) → 결과 화면
[결과]    점수 + 테두리 겹침 + 한 줄 평 (화면 5). 어긋난 곳 표시·숫자 없음
[판정]    "다음"(점수 낮아도 가능, 이 점수로 확정) / 재시도 → 완성본부터 / 건너뛰기(합산 제외). 자동 통과 없음
[이동]    진행 칩에서 아무 단계나 눌러 돌아가기. 다시 확인받으면 최신 결과로 갱신
```

## 8. 한 사람의 세션

> 스모키 아이를 처음 해 보려는 24세. 앱을 켠다. 서버 처리에 동의하고, 안내대로 정면에서 눈을 감았다 뜨고 고개를 좌우로 돌리며 4장이 자동으로 찍힌다.
>
> 룩 10개가 나온다. 아직 안 만들어진 룩은 "로딩 중". 하나씩 누르면 카메라 속 내 얼굴 위에 그 화장이 얹혀 고개를 돌려도 따라온다. 스모키를 고르니 "이 룩에 쓰인 것: 다크 브라운 섀도우(매트), 블랙 젤 라이너, 핑크 파우더 블러셔, MLBB 립"이 나온다. "이 룩으로 시작"을 누르자 내 얼굴에 스모키가 다 된 모습 한 장이 뜨고, "시작"을 누른다.
>
> 첫 부위는 눈썹. "폰을 가로로 돌리세요" 안내가 뜨고, 완성 예상 얼굴을 양쪽 눈썹으로 줌한 모습이 보인다. "지금 필요한 것: 브라운 아이브로 펜슬". "그리러 가기"를 누르면 눈썹 자리에 테두리가 얼굴을 따라 뜬다. 폰을 두고 거울로 가서 그린다. 중간에 돌아와 테두리를 한 번 더 보고 다시 거울로 간다. 다 그리고 돌아와 "확인받기"를 누르니 91점. "다음".
>
> 아이라이너. 확인받기를 누르니 82점과 함께 내 눈 위에 가이드 테두리가 겹쳐 보이고 "오른쪽 꼬리가 조금 위로 갔어요. 왼쪽에 맞춰 살짝 내려 그리세요"가 뜬다. 재시도를 누르자 완성본부터 다시 보여주고, 지우고 다시 그린 뒤 89점, "다음". 섀도우는 눈을 감으라는 안내와 함께 눈꺼풀 위에 테두리가 뜬다. 확인하니 "방향이 잘 맞아요. 왼쪽을 조금만 더". 입술 차례에 "폰을 세로로 돌리세요". 입술, 볼터치를 지나 마지막 쉐딩·하이라이트. 완성본에 "둥근 얼굴형이라 턱선과 광대 아래에 쉐딩을, 광대 위에 하이라이트를 넣었어요"가 뜬다. 확인하니 점수 없이 "확인하고 넘어가세요. 오른쪽이 조금 진해요". 거울에서 경계를 풀고 "다음".
>
> 중간에 눈썹이 마음에 안 들어 진행 칩에서 눈썹을 눌러 돌아가 다시 확인받고 온다. 전체 리뷰에서 부위별 점수와 한 줄 평, 합산 78점이 뜨고, 처음 찍은 쌩얼과 지금 내 화장이 나란히 보인다. "결과 저장"으로 비교 사진을 갤러리에 남기고 "끝내기".

## 9. 범위

**한다**: 매 세션 맨얼굴 4장 촬영, 룩 10개 실시간 얹어보기, 룩별 제품 종류·색 계열 표시, 전체 완성 예상 한 장, 부위 완성본 + 실시간 테두리, 버튼 방식 확인받기, 눈썹·아이라이너·입술 형태 채점, 섀도우·볼터치 강도 채점(유무·방향·좌우), 쉐딩·하이라이트 가이드(얼굴형 규칙)와 확인만, 부위 점수·합산(화면엔 점수·한 줄 평만), 쌩얼 vs 내 화장 비교, 결과 이미지 갤러리 저장, 모바일 웹.

**하지 않는다**: 얹어보기를 채점 정답으로 사용, 자동 채점(버튼 없이), 바르는 도중 실시간 채점, 그라데이션 균일도 채점, 뜸·갈라짐 판정, 쉐딩 점수·절대 강도, 다른 사람·다른 폰·다른 날과의 비교, 피부 진단, 브랜드·상품명 추천, 음성 안내, 3D 얼굴 모델, 얼굴형에 따른 룩·눈·입술 조정(쉐딩·하이라이트만 예외), 세션 기록 보관, 결과 화면에 숫자 표시.

## 10. 원칙

- **정직한 측정**: 못 재는 건 점수 안 준다. 못 잰 부위는 합산에서 뺀다.
- **사용자가 촬영 시점을 정한다**: 채점은 "확인받기"를 눌렀을 때만.
- **기기 안에서**: 사진·결과는 세션 동안만 기기 보관, 끝내면 삭제. 서버는 얹어보기 생성·쉐딩 위치 산출에만 쓰고(정면·좌·우 3장) 원본은 처리 후 즉시 삭제. 서버 처리에 동의하지 않으면 서비스를 쓸 수 없다. 결과 저장은 사용자가 고르는 갤러리 이미지 한 장뿐.
- **규칙 출처 공개**: 가이드·제품 목록의 근거를 앱 안에서 볼 수 있다.
- **룩은 그대로**: 얼굴형 개인화는 쉐딩·하이라이트 위치에만. 나머지 부위와 룩은 조정하지 않는다.

## 11. 한 문장 포지셔닝

**"AR 트라이온이 '어떻게 보일지'를 보여줄 때, 당화응은 오늘의 내 얼굴에 얹어 보고 고른 화장을 '무엇으로, 어디에, 어떻게'까지 보여주고, 한 부위씩 '잘 됐는지' 확인시켜 준다."**
