# `guide-portrait-lock` — 입술 · 볼 · 쉐딩은 세로에서만 · 섀도 눈꼬리 연장을 테두리에도

두 가지를 같이 한 브랜치: (1) 세로 부위도 방향 잠금, (2) 꼬리 있는 섀도 화장의 꼬리를 화면 3 · 4 테두리에도 (`guide-shadow-tail` 를 합침).

## 한 일

- **세로 잠금** — `orientation-lock`: 부위가 원하는 방향과 다르면 막음(눈 부위 가로 · 나머지 세로), 문구 `rotateText(part)`. 게이트도 세로 부위 + 가로면 "폰을 세로로 돌려 주세요"(3초 규칙으로도 안 넘어감). 결정 기록 F3
- **섀도 꼬리 테두리 (#30)** — `personal-guide.shadowTail()`: 섀도 영역 끝에 이어 붙이는 두 점(꼬리 끝 = 눈꼬리에서 라이너 꼬리 방향으로 눈 폭 × 0.35). 칠하기(`makeup-paint`)와 테두리가 같은 함수를 씀. 채점 영역은 그대로(그리기 전용 칸 `PartGeometry.shadowTail`)

## 트러블슈팅

- **섀도우 다음 입술로 넘어갈 때 가로 그대로 진행됨**
  - 원인: 눈 부위만 막고 나머지는 껍데기 안내 한 줄뿐. 가로면 카메라가 옆이라 얼굴이 약 16° 돌아간 것으로 찍혀(#239) 각도 차 → 3초 규칙 → "확인만(정렬)" 으로 끝나기 쉬움
  - 해결: 화면 3 · 4 · 5 모두 세로로 막음
- **방향을 모르는 브라우저에서 눈 부위만 안 막힘** — 예전엔 모르면 "가로" 로 봤음 → 모르면 `null` 로 두고 아무것도 안 막게
- **꼬리 있는 화장인데 테두리엔 꼬리가 없음**
  - 원인: 완성본 · 2-b 엔 꼬리가 칠해지는데(#250) 테두리는 섀도 영역만
  - 해결: 칠하기와 테두리가 같은 함수 → 어긋날 수 없음. "칠한 띠 = 테두리" 를 점 하나까지 같은지 시험(T4)
  - 채점 영역까지 넓힐지는 ⑥ 이 정하도록 남김(→ 이후 `guide-shadow-score-tail` 에서 넓힘)
- 껍데기 위 안내 줄과 문구가 두 번 보일 수 있음 — 거슬리면 하나로
