### #174 [score] 맨얼굴 오채점 수정(#169) · 합산 보정 켜기(#35) · 채점 이벤트(#37)
- 브랜치: `score` · 병합 2026-09-29 · +341 −25
- 한 일: 라이너를 안 그린 맨얼굴에 라이너 막대가 가득 차고 눈썹 56점이 나오던 오채점을 고쳤다. 합산의 대칭 · 조화 보정에 필요한 값을 채점이 넘기게 하고, 채점 이벤트 테스트를 한 줄 더했다. Refs #169, Closes #37 #35.
- 결과: 합성 얼굴 기준 — 맨얼굴 1px 어긋남: 라이너 64점 · 옅은 눈썹 82점 → 둘 다 확인만. 맨얼굴 2px 어긋남(6방향): 59~72점 → 확인만. 그린 라이너 1px 어긋남 91~96점, 그린 눈썹 98점 → 90점 이상 유지. `tests/bare-shift.test.ts` 14개, `review-inputs.test.ts` 6개. `check.sh` 통과(vitest 368, 리뷰 반영 뒤 379). 라이너 한 장 4 → 23ms(PC), 리뷰 반영 뒤 25ms.
- 트러블슈팅:
  - 증상: 맨얼굴인데 라이너 · 눈썹 점수가 난다 → 원인: 채점은 "쌩얼 대비 색이 바뀐 곳 = 그린 곳" 인데, 맨얼굴에도 속눈썹 · 눈썹 털이 있어 두 사진이 1~2px 만 어긋나도 원래 속눈썹이 "새로 그린 선" 으로 보였다. 웹캠 얼굴 점은 원래 1~2px 흔들리고 게이트가 허용하는 각도 차(yaw 8°)만으로도 그만큼 어긋난다. 조명 · 색온도 · 카메라 잡음은 원인이 아니라고 실험으로 확인했다 → 라이너(눈마다) · 눈썹은 비교 전에 지금 사진을 ±2px 옮겨 보고 쌩얼과 가장 잘 겹치는 자리에서 비교한다(`REGISTER.maxPx` 2, `register()`).
  - 정렬 기준을 색 차이 전체로 했더니 그린 선을 원래 속눈썹 위로 끌어다 겹쳐 라이너가 75점(69점)으로 떨어졌다 → 라이너 · 눈썹 화장은 어둡게만 하고 털이 어긋나면 털 자리가 밝아지므로, "쌩얼보다 밝아진 양" 만 정렬 비용으로 쓴다(`stripCost` · `meanLighter`).
  - 예전 합성 얼굴은 살색 판이라 맨얼굴 테스트(N1)가 너무 쉽게 통과했다 → 속눈썹 · 눈알 · 옅은 눈썹 털이 있는 자연 맨얼굴 `NATURAL` 을 만들었다.
  - 눈썹이 대칭 보정에서 빠지고 조화 보정이 언제나 0 이었다 → 채점이 값을 안 넘겼기 때문이다 → 눈썹 `metrics.lrDiff`, 볼 · 입술 `metrics.colorAb` 를 넘긴다.
  - (리뷰 댓글 반영 `abbfbfc`) 카메라 잡음 — 한 픽셀씩 색을 읽어 픽셀마다 잡음이 따로 붙으면 맨얼굴에도 점수가 났다(잡음 σ6 에서 15/15). #169 의 더 큰 원인이었을 가능성이 있다 → 샘플을 눈 폭 1/30 창 평균(합성 얼굴 3×3)으로 읽는다. 3×3 에서 σ6 · σ10 맨얼굴 오채점 0, 그린 라이너 최저 91 이다(2×2 는 σ10 에서 15/15, 6×6 은 가는 선이 흐려져 82).
  - (리뷰) σ10 에서 흩어진 몇 행으로 25점이 났다(20회 중 4회) → 라이너 감지를 "3행 이상" 에서 "3행 이상이면서 행의 10% 이상" 으로 바꿔 0회가 됐다.
  - (리뷰) 조화 보정 — 볼 영역 평균은 대부분 피부색이라 입술색과 늘 멀어서 잘 어울리게 그려도 −5(최대)였다 → `rules/looks.json` `harmonyRange` 를 null 로 두어 껐다. `colorAb` 는 계속 넘긴다.
  - (리뷰) 미세 정렬 범위가 픽셀 고정이면 웹캠엔 너무 크고 폰엔 너무 작다 → 눈 폭 비율 2.2% 로 바꿨다. 잡음 때문에 옮겨져 그린 눈썹이 94 까지 떨어지는 것 → 비용이 0.1 이상 줄 때만 옮긴다(진짜 어긋남은 라이너 2.2~3.6 · 눈썹 0.1~0.2 줄고, 잡음은 0.03 이하).
  - (리뷰) 눈썹 좌우 높이 차에 각자 두께를 곱하면 원래 두꺼운 쪽이 "높게 그렸다" 로 읽혔다(두께만 다른 눈썹 0.028) → "자기 눈썹 안 위치 × 좌우 공통 두께" 로 재서 0 이 됐다.
- 남긴 것: 모두 합성 얼굴 실험이다. 실제 사진(골든 세트, 지금 0장)과 폰으로 확인해야 한다. 앞머리가 눈썹을 덮는 경우와 "오른쪽 선이 밖으로 번졌어요" 는 재현하지 못해 이것으로 안 풀릴 수 있다. 입술 · 섀도 · 볼은 건드리지 않았다. 결과 화면 테두리는 정렬 전 프레임에 그린다(최대 2px 차이). 조화 보정은 실제 사진으로 기준을 잡으면 켠다.
