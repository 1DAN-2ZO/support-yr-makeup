# `flow-poc` — 부위 가이드를 사진 · 실시간으로 같이 보기 · 섀도 부채꼴 · 음영 빼기 · 새 흐름 한 바퀴 POC

## 한 일

- **실시간 가이드 = 예전 화면 4 엔진 그대로** — 얼굴 그물 붙이기 · 떨림 거르기 · 먼 쪽 눈 보정(C+F+G2+G3+H) · 크게 돌리면 흐리게 · 부위 확대 창(crop-follow) · 청록 점선. 선 모양만 정답사진 부위 가이드로
  - `createLiveRun` 에 `outline` 옵션: 맨얼굴 좌표로 이미 그린 모양을 넣으면 템플릿 대신 그 모양을 따라감 (L47 · L48)
- **부위 칩** [전체 / 눈썹 / 아이라이너 / 아이섀도 / 입술 / 블러셔] 를 사진 · 실시간이 같이 씀. 사진도 고른 부위로 확대 (선 굵기는 그대로)
- **섀도 윗선** — 가장 높은 점들만 매끄럽게 이어 부채꼴 (시작점 · 끝점은 그대로, SH5)
- **섀도 자리 음영 빼기** (`makeup-extract.ts`, X18) — 피부색 그대로 어두워지기만 한 곳(색 방향 10° 안, 채도 안 늚)은 화장으로 안 셈
- **새 흐름 POC** — 맨얼굴 → 참고 사진 → 정답사진(klein) → 부위 가이드(자른 정지 사진 + 테두리) → 시도사진 → 피드백 → 저장. 화면 6 피드백은 ③ 화면이 오기 전 흐름을 돌려 보려는 간단 비교(`core/guide-feedback.ts`: 덜 그림 · 넘침, 점수 없음, 블러셔는 확인만)
- **찍기 기준** (`snapshot.ts`) — 가만히 기준 얼굴 폭 0.4% → 1%, 2초 안에 못 모으면 가장 덜 움직인 5장 (S7 · S8). 테스트 페이지 · POC 는 카운트다운 뒤 얼굴이 보이는 첫 장을 바로

## 트러블슈팅

- **섀도가 너무 울퉁불퉁 (POC 실사진, 사용자)**
  - 원인: 칸마다 보이는 높이를 그대로 이어서 꺼진 곳마다 들어감
  - 해결: 사용자 제안대로 "시작점 · 끝점만 맞추고 높은 점들을 이어 부채꼴" — 눈 좌표에서 위로 볼록한 껍질 → 고른 간격으로 다시 찍어 이웃 평균
  - 예전 시험 S8(양 끝이 세로로 끊기지 않는지)은 끝 1px 안만 봐서 3px 안쪽에서 16px 솟는 벽도 통과 → 끝점과 3px 안쪽 높이를 같이 보게. SH5 도 처음엔 점이 촘촘해 약해서 3px 간격으로 꺾임 각도를 재게 고침
- **사람 눈엔 음영과 섀도가 다른데 컴퓨터는 섞어 잡음**
  - 원인: AI 가 눈두덩을 다시 그리며 오목한 곳을 어둡게 해서 섀도 위 음영까지 섀도로
  - 해결: "색은 그대로 어두워지기만" 하면 음영. 색이 바뀐 곳(금색 · 갈색) · 더 선명해진 곳 · 반짝여 밝아진 곳은 그대로 섀도
  - 한계: 피부와 같은 색 방향으로 어둡게만 하는 음영 섀도는 같이 빠짐
- **실시간이 예전 엔진이 아니라 사진용 방식으로 돌아감 (사용자: "실시간은 옛날 방식으로 불가능한가?")**
  - 처음엔 가이드 점을 그물에 붙여 옮기기만 해서 떨림 거르기 · 먼 쪽 눈 보정 · 확대 창이 없었음
  - 해결: 템플릿이 없어도 엔진은 그대로 쓸 수 있게 `outline` 옵션. 템플릿 섀도 전용 퍼지는 방향 표시는 다른 모양에 붙이면 엉뚱한 자리에 생겨서 넣은 모양엔 안 붙임 (블러셔 방사형만 페이지에서)
- **PC 웹캠에서 "가만히 있어 주세요" 에서 안 넘어감** — 웹캠(640×480)은 얼굴 점 떨림만으로 0.4% 를 넘음 → 1% · 2초 뒤 가장 덜 움직인 5장 → 그래도 번거로워 "그냥 찍기로 바로" (사용자)
- **찍기 버튼이 없는 옛 화면이 뜸** — 브라우저가 옛 빌드를 들고 있었음, 새로 고침으로 해결
- **POC 피드백이 이상함**
  - 똑같은 사진을 넣었는데 눈썹이 "덜 칠함" → 가이드 모양 전체가 아니라 정답사진에서 실제로 칠해진 자리와 비교
  - 맨얼굴을 넣었는데 가는 라이너가 "가이드대로" → 가는 가이드는 깎지(erode) 않게 (F9 · F10)
- **같은 맨얼굴로 다시 돌려 보기 어려움** — 클립보드로 붙인 맨얼굴은 디스크에 안 남음 → POC 화면 1 에 '맨얼굴 저장'
- 화면 없는 크롬에 맨얼굴 사진으로 가짜 카메라를 넣어 POC 1 → 7 한 바퀴 확인 (정답사진을 넣으면 전부 "가이드대로", 맨얼굴이면 전부 "안 칠함")
