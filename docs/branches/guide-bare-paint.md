## 트러블슈팅

- **AR 장면 방식의 문제 (#190 → #192)**
  - 누르는 순간 자세에 따라 비뚤기 쉽고, 앱을 다시 켜면 장면이 없고, 채점(쌩얼 비교)과 다른 얼굴이었음
  - 해결: 쌩얼 정면 + 같은 계획 → 완성본 · 테두리 · 채점이 한 얼굴. 2-b AR 이 안 켜졌어도 완성본이 나옴
- **사진이 한 장이라 '휘기' 가 필요 없음**
  - AR 은 기준 얼굴 → 지금 얼굴로 휘어 붙이지만, 여기선 기준 점 = 지금 점으로 넣어 휘기 없이 그림
- **그리기 실패 대비**
  - 계획이 없거나 WebGL2 가 없으면 쌩얼 + 테두리로 (흐름은 안 막음). GS5~GS8 — 크기 안 맞추기 · 화장 안 그리기 · 원본 안 쓰기를 일부러 넣어 각각 실패 확인
