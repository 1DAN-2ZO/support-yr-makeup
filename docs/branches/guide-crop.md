## 트러블슈팅

- **눈 부위가 5배 확대돼 한쪽 눈 · 피부만 보임**
  - 원인: 자동 회전이 꺼진 채 폰을 가로로 돌리면 화면은 세로 그대로, 영상 속 얼굴만 90° 누움. 확대 폭을 두 눈의 **x 차이**로 잡아서 누운 얼굴(두 눈이 위아래)에선 폭이 거의 0 (합성 얼굴: 364px → 75px)
  - 해결: 폭을 두 눈 사이 **거리**로 → 기울거나 누워도 확대가 안 커짐. 45° 넘게 누우면 확대하지 않고 자동 회전 안내
- **누운 얼굴이 "얼굴 없음" 으로 떨어짐**
  - 원인: 옛 정면 각도 식이 0 으로 나눠 NaN → 깨진 값 검사에 걸림
  - 해결: 기울기를 깨진 값 검사보다 먼저 봄 (L20 이 잡음)
- **떨림이 배율만큼 커 보임** — 확대 1.3 → 1.7 (가정값, ⑥ 제안 1.6~1.8)
- **세로도 쓰게 했다가 되돌림**
  - 첫 커밋은 #204 제안대로 세로에서도 눈 부위를 쓰게 했는데, 팀 협의(정의서 3-2 "눈 · 눈썹 단계는 모두 가로")와 달라 둘째 커밋에서 세로를 막음
- **브라우저는 화면을 강제로 못 돌림 (iOS)** — 돌리기 전엔 못 넘어가게 하고, 돌리면 껍데기가 다시 그려 원래 내용이 나오게
- **⑥ 제안 시험 "크기가 같다" 를 바꿈** — 누운 얼굴은 두 눈이 위아래로 서서 같은 크기면 눈이 잘림 → "작아지지 않고 다 담는다" (C1)
