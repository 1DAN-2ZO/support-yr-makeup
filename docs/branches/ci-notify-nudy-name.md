### #351 [ci] 디스코드 PR 알림 이름을 "당화응 PR" → "nudy PR"
- 브랜치: `ci-notify-nudy-name` · 열림 · +1 −1
- 한 일: 디스코드에 PR 알림이 옛 서비스 이름 "당화응 PR" 로 올라오던 것을 "nudy PR" 로 바꿨다(`.github/workflows/notify.yml` 한 줄). 이슈 알림은 이미 "nudy 이슈" 였고 PR 알림만 옛 이름으로 남아 있었다.
- 결과: 알림 설정 파일의 글자 한 곳만 바뀐다. 앱 · 서버 코드는 그대로다. 테스트 수는 본문에 없음.
- 트러블슈팅: 없음
- 남긴 것: main 에 올리면 프론트 · 백엔드 자동 배포가 돌아 사이트가 잠깐 내려가서, 급하지 않아 다음 PR 과 같이 올리기로 했다. 바뀐 이름은 병합된 뒤에 올라오는 PR 알림부터 보인다.
