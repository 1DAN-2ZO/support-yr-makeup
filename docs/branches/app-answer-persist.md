- 트러블슈팅:
  - 문제: 정답사진이 메모리에만 있어서 새로고침하면 사라졌고, 한 장에 15초쯤 걸리는 그림을 다시 만들어야 했다 → 푼 방법: 폰 세션 저장소에 쓰고 앱을 켤 때 되살린다. 바로 읽게 메모리에도 든다.
  - 문제: 저장이 실패할 수 있다(저장공간 부족 · 사생활 보호 모드) → 푼 방법: 이번 세션에서는 메모리 것으로 쓴다(MP8).
  - 문제: 옛 맨얼굴에 겹치던 그림이 새 사진과 견줘질 수 있다 → 푼 방법: 짝이 깨지면 버린다. 정답사진이 바뀌면 옮긴 그림을, 맨얼굴을 다시 찍으면 둘 다 버린다.
  - 문제: 끝내기가 지운 뒤에 그림이 다시 써질 수 있다 → 푼 방법: 쓰기를 draft 저장과 같은 줄에 세웠다.
  - 리뷰 지적(① 댓글): 맨얼굴을 다시 찍으면 `made.clear()` 가 맨얼굴 저장 뒤에 줄 서 있어서 그 사이 잠깐은 `getAnswer()` 가 옛 정답사진을 돌려준다 → 그때는 아직 촬영 화면이라 고칠 필요는 없다고 봤고, 서버 연결 PR 에서 같이 보기로 했다.
  - 리뷰 지적(댓글): 끝내기를 안 누르고 탭을 닫으면 사진이 2시간 뒤 다시 열 때에야 지워지고(만료 확인이 앱을 켤 때만 돈다), 다시 안 들어오면 폰에 계속 남는다. 이 PR 로 정답사진 · 옮긴 그림도 같은 칸에 들어간다 → 푼 방법: 동작은 그대로 두고 동의 화면에 "끝내기를 누르면 바로 지워져요. 누르지 않고 닫으면 폰에 남아 있다가, 2시간이 지난 뒤 다시 열 때 지워져요." 문장을 넣자고 제안했고, ⑤ 모델/UI 담당이 #347 로 넣어 같이 병합했다.
