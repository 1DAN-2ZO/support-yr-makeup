# `guide-shadow-score-tail` — 섀도 채점 영역도 꼬리까지

꼬리 있는 화장(시크 · 아이돌 · 스트릿 · 키치)은 화면 3 · 4 테두리에 섀도 꼬리가 그려지는데(#284), 채점은 꼬리 없는 영역만 봤음. ⑥ 결정(#284 댓글)대로 채점 영역도 테두리와 같은 모양으로 넓힌 브랜치. 채점 결과가 바뀌어서 따로 올림.

## 트러블슈팅

- **테두리대로 꼬리까지 칠했는데 오히려 덜 칠한 것으로 나옴**
  - 원인: 섀도 진하기는 '영역 안 평균' 을 '둘레 맨살 띠(영역 1.3 ~ 1.8배)' 와 비교. 꼬리 색이 맨살 띠 쪽에 들어감
  - 해결 후: 합성 얼굴에서 꼬리 자리만 칠했을 때 섀도 변화량 −0.5 → 3.4 (시험 T5)
- **전후 점수 비교 (합성 얼굴, 방향만 보는 용도)**
  - 꼬리까지 칠함: 그러데이션 100 → 100, 단색 시크 81 → 78 · 스트릿 98 → 96
  - 꼬리 빼고 칠함 (단색): 시크 78 → 97 · 스트릿 96 → 100 — 넓힌 영역의 빈 꼬리 자리가 평균을 묽혀서 '조금 진해요' 가 줄어듦. 진하기가 영역 평균이라 생기는 일로, #260(범위를 안 잼)과 같은 얘기
  - '눈꼬리 쪽이 더 진해야' 지적이 칸마다 생기거나 사라짐 — 합성은 두 쪽을 같은 진하기로 칠해 차이가 0 근처라 뒤집히는 것. 꼬리 효과로 보기 어려움
- **실제 얼굴로 못 돌림** — ③ 합성 세트(`eval/samples/paint_levels.mjs`)는 `lookGuide` 를 써서 꼬리가 안 들어감(앱은 `planGuide`). 로컬에 FFHQ 사진도 없음
- 변이: 꼬리 두 점 순서를 뒤집으면 T2 · T4 실패
