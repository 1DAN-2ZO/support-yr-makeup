- 브랜치: `vlm-flow` · 병합 2026-09-29 · +781 −182

- 결과: `check.sh` 통과(vitest 623 · pytest 75). 새 시험: vlm-client 4 · vlm-flow 5 · vlm-image 1 · 화장 목록 타일 2.
- 트러블슈팅:
  - VLM 제안이 관문에서 거절되는 경우 → 이유를 붙여 한 번 더 묻고, 그래도 남은 거절 항목만 규칙값으로 채운다(`core/vlm-flow.ts`).

  - 서버 처리 화면에서 멈춘 채 되살린 세션 → 화장 선택으로 보낸다.
  - ④ 서버 담당의 중간 서버가 아직 없다 → 가짜 서버 `scripts/dev-vlm-mock.mjs` 로 흐름을 돌려 본다.
