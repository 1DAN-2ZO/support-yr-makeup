# `guide-fade-25-40` — 먼 쪽 눈 흐리게 구간을 5° 씩 일찍 (30→45 → 25→40)

화면 4 에서 고개를 크게 돌리면 먼 쪽 눈 테두리를 흐리게 하는 구간(후보 1, #288)을 5° 씩 앞당긴 브랜치. 먼 쪽 눈 보정(12 → 25°)이 끝나는 자리에서 바로 흐려지기 시작하는 셈.

- 기간: 2026-10-05
- PR: #310 (머지) — Refs #288 · #290

[← 브랜치 목록](README.md)

## 한 일

- `live-run.ts` `FAR_FADE` `{ from: 30, to: 45 }` → `{ from: 25, to: 40 }` (가장 옅게 0.3 은 그대로)
- 눈 부위(눈썹 · 라이너 · 섀도우) 먼 쪽 눈 테두리만, 채점은 안 바뀜

## 트러블슈팅

- **시험(L36)이 새 시작점과 겹침**
  - 원인: 원래 "각도 차 약 25 면 안 흐려짐" 한 점만 봤는데, 새 시작점이 바로 25
  - 해결: 각도를 화면 4 눈금(`rigidPoseDiff`)으로 여러 개 재서 25 아래 그대로 · 25 ~ 40 차츰 · 40 넘으면 가장 옅게를 모두 확인 (경계 하나만 보던 것 대신)
  - 변이(실제로는 30° 부터 흐려지게) → 27.9° 에서 실패 확인
