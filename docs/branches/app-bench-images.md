### #276 [app] 벤치 샘플 이미지 16장을 저장소에서 뺌 — 숫자와 글만 남김 (#118)
- 브랜치: `app-bench-images` · 병합 2026-10-01 · +4 −2
- 한 일: 이슈 #118 의 A 안대로 `poc/look-tryon/server-bench/results/` 의 샘플 이미지 `*.jpg` 16장을 저장소에서 지웠다. `results.csv` 와 README 의 표 · 육안 평가 글은 그대로 뒀다. `.gitignore` 에 벤치를 다시 돌려도 이미지가 커밋되지 않게 넣었고, README 에 뺀 이유를 적었다. 실험 코드(`bench.py` 등)는 건드리지 않았다.
- 결과: 본문에 없음(검사 결과가 적혀 있지 않다).
- 트러블슈팅:
  - 저장소에 실존 인물 얼굴 사진이 들어 있었다 → Stable-Makeup · SHMT 저장소에 딸려 온 사진과 그것으로 만든 결과물이다. SHMT 는 비상업 라이선스이고, 찍힌 사람의 동의를 확인할 수 없다(`data-plan-v6.md` 의 기준). 개인화가 VLM 방식으로 바뀌어 이 벤치는 안 쓰는 옛 방식의 기록이다 → 이미지를 빼고 숫자와 글만 남겼다.
  - 이슈에는 15장이라고 적혀 있었다 → 세어 보니 16장이었다(LCM-LoRA 결과 3장 포함).
  - 채점 담당이 가져온 EasyPortrait 로 다시 돌리는 안(C)도 검토했다 → 라이선스로는 가능하지만(비상업 조항 없음 · 출처 표기와 같은 조건 공개 필요) 초상권은 라이선스에 없고, 화장 참조 사진 짝이 없고, 안 쓰는 옛 방식을 다시 돌려야 해서 하지 않았다.
- 남긴 것: 옛 커밋에는 사진이 남아 있다. 이력 되감기는 금지라 여기까지만 했다. 저장소를 공개할 때 이력째 공개할지 새 저장소로 옮길지는 그때 따로 정한다.
