# 당화응 데이터셋 — 팀 공유용 정리 (2026-09-17)

조사 70여 종 중 7종은 실제로 받아서 우리 파이프라인(MediaPipe 랜드마크 → 부위 마스크 → 채점)으로 200장씩 돌려 봤다. 순위는 "우리가 사용하기 좋은 순서"다.

## 6. 라벨링·파인튜닝 계획

| 항목 | 결정 | 이유 |
|---|---|---|
| 클래스 | 배경, 눈썹, 아이라이너, 섀도우, 입술, 볼터치 (좌우 없음) | 합성 데이터와 같아야 섞어서 학습 |
| 장수 | 1차 200장 (20명 × 10장), 2차 500장 | 소규모 파인튜닝 표준 규모 |
| 사람 | 팀원 6명 + 지인 14명, 동의서 서면 | 초상권 |
| 촬영 | 얼굴이 화면 폭 60% 이상, 조명 3종, 각도 정면·15°·30° | 팀원 셀피 20장은 홍채 12px로 미달이었음 |
| 단계별 촬영 | 맨얼굴 → 눈썹 → 라이너 → 섀도우 → 립 → 볼터치 6장 | 단계 전후 ΔE가 곧 마스크 초안 |

| 라벨링 순서 | 방법 |
|---|---|
| 초안 1 | 랜드마크 다각형 (입술·눈은 거의 맞음, 눈썹만 고침) |
| 초안 2 | 단계별 ΔE 차이 (피부 중앙값 + 6 기준) |
| 손 라벨 | CVAT에서 브러시로 고치기만. 장당 5분, 200장 = 6명 × 3시간 |
| 품질 | 20장은 두 명이 라벨해 Dice 0.80 이상 확인 |
| 저장 | 정수 라벨 PNG, 합성 생성기와 같은 형식 |

| 파인튜닝 단계 | 무엇 | 이유 |
|---|---|---|
| ① 파싱 뼈대 | EasyPortrait로 눈썹·눈·입술 학습 | 상업 가능 계열. CelebAMask 가중치는 안 씀 |
| ② 화장 클래스 | 합성 2,000장으로 라이너·섀도우·볼터치 추가 | 실사진만으로는 작은 클래스를 못 배움 |
| ③ 실사진 파인튜닝 | 실사진 200 + 합성 200을 1:1, 낮은 학습률 | 합성만은 안 되고 실사진만은 과적합 |
| ④ 증강 | 색온도·밝기·좌우뒤집기·회전·JPEG | 조명 3종 사이를 메움 |
| ⑤ 평가 | 학습에 없는 사람 4명, 클래스별 IoU, 맨얼굴 오검출 | 같은 사람이 양쪽에 있으면 점수 부풀음 |
| ⑥ 배포 | ONNX → 브라우저 | 속도 목표에 맞춤 |

| 합격선 (1차) | 기준 |
|---|---|
| 눈썹·입술 IoU | 0.7 이상 |
| 라이너·섀도우·볼터치 IoU | 0.5 이상 |
| 맨얼굴 오검출 | 1% 이하 |
| 못 넘으면 | 못 맞춘 조건 위주로 2차 300장 |

학습에 들어가는 것: EasyPortrait + 우리 합성 + 우리 촬영 → 상용 가능. LaPa·CelebAMask·FFHQ-Makeup·FaceSynthetics는 평가·비교에만.
