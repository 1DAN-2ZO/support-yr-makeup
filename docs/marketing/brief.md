# 당화응 마케팅 브리프

2026-09-22 작성 · 담당 ⑥

> **이 문서는 마케팅 작업의 출발점이다.** 홍보 문구·설문·발표 자료·모집 글을 쓰는 사람은
> 전부 여기서 시작한다. 여러 사람이 각자 다른 말을 하면 서비스가 뭔지 흐려진다.
>
> **숫자와 사실의 원본은 이 저장소다.** 산출물은 `support-yr-makeup-marketing` 에 쌓는다.
> 숫자가 바뀌면 이 문서를 고치고, 산출물 쪽에 베껴 적지 않는다.

---

## 1. 한 줄

**폰 웹으로 화장을 가르쳐 주고, 내가 바른 것을 채점해 주는 서비스.**

맨얼굴을 찍으면 → 룩을 고르고 → **내 얼굴 위에 어디에 뭘 칠할지 선을 그려 주고** → 다 하면 얼마나 비슷한지 점수를 낸다.

앱 설치 없이 브라우저에서 돈다.

## 2. 누구에게

**새로운 화장을 배우고 싶은 사람.**

- 처음 색조를 시작하는 사람
- 안 해 본 룩을 익히려는 사람
- **유튜브를 따라 해도 내 얼굴에서는 안 되는 사람**

> 세 번째가 핵심이다. 영상은 남의 얼굴에서 되는 걸 보여 준다. 우리는 **내 얼굴**에 그려 준다.

## 3. 사용자가 겪는 순서

```
동의·촬영 4장 → 룩 10개 중 선택 → 다 하면 이런 얼굴(완성 예상)
  → 부위별로: 어디에 그릴지 보여줌 → 따라 그림 → 확인받기 → 점수
     (눈썹 · 아이라이너 · 섀도우 · 입술 · 볼터치 · 쉐딩)
  → 전체 리뷰: 합산 점수 + 맨얼굴 대비 + 결과 저장
```

**한 번에 다 그리고 한 번에 채점하지 않는다.** 한 부위를 확인받고 "다음"을 눌러야 다음으로 간다.

## 4. 차별점 — 조사해서 좁힌 것

### 먼저 인정할 것: 이 분야는 이미 대기업이 하고 있다

| 서비스 | 누가 | 무엇을 |
|---|---|---|
| **워너-뷰티 AI** | 아모레퍼시픽 + KAIST | 얼굴 분석 → 화장법 추천 → 가상 체험 → 음성 챗봇 상담. **CES 2025 AI 부문 혁신상** |
| **YouCam Tutorial** | Perfect Corp (2021) | 아티스트가 그린 순서를 **AR 브러시 애니메이션**으로 얼굴에 겹쳐 보여 줌. "세계 최초 대화형 AR 메이크업 교육 플랫폼" |
| **YouCam Makeup** | Perfect Corp | 가상 착용, 얼굴 보정, AI 스타일 추천 |
| **ModiFace** | L'Oréal | 가상 착용·피부 진단. **누적 1.2억 회 · 66개국 · 31개 브랜드** (2025년 말) |
| Facetopo · Makeup Check AI · JAMME | — | 얼굴 분석 / 사진 평가 |

**워너-뷰티와 우리는 셋이 겹친다** — 얼굴 형태 분석, 다른 사람 화장을 내 얼굴에 적용, 전문가 노하우 기반 추천.

> **이걸 숨기지 않는다.** 모르고 발표하면 질문 한 번에 무너진다. 먼저 인정하고 좁히면 훨씬 단단하다.
> 그리고 대기업이 한다는 건 **시장이 실재한다는 증거**다.

### 그런데 전부 공통으로 없는 것

```
기존:    보여 준다  →  사용자가 따라 한다  →  ???
                                              ↑
                                  내가 제대로 했는지 아무도 안 본다

당화응:  보여 준다  →  내가 바른다  →  확인받기  →  점수 + 한 줄 평
```

**어느 서비스도 사용자가 실제로 바른 것을 보지 않는다.**

학계도 같은 지적을 한다:

> **"기존 AR 튜토리얼 대부분이 실시간 오류 피드백을 주지 않는다"**
> — OperARtistry, 2023 (arXiv:2311.11269)

같은 논문이 **단계별 AR 가이드가 비디오 튜토리얼보다 짧은 시간에 더 높은 완성도**를 낸다고 했다. 우리 존재 이유이면서 차별점이 어디인지도 같은 논문이 말해 준다.

### 축이 다르다

| | 그쪽 | 당화응 |
|---|---|---|
| 답하는 질문 | **무엇을 바를까?** | **어떻게 바르나? 잘 발랐나?** |
| 성격 | 상담·체험 도구 | **연습 도구** |
| 언제 쓰나 | 화장하기 **전** | 화장하는 **동안**, 한 **뒤** |

### 남는 차별점 넷

1. **내가 실제로 바른 것을 본다** — 여전히 유일
2. **부위별로 끊어서 확인받는다** — 한 번에 결과가 아니라 여섯 단계
3. **세션마다 기준을 새로 만든다** — 기존은 사진 한 장 등록. 우리는 매번 맨얼굴 4장으로 오늘의 색·척도·조명 기준을 잡는다. 어제 조명과 오늘 조명이 다르면 같은 화장도 다르게 보이기 때문
4. **브랜드에서 독립 · 설치 없는 웹** — 화장품 회사가 만들면 추천이 곧 자사 제품이다. 우리는 **제품 종류**만 말한다("브라운 펜슬"). 집에 있는 걸 쓰게 하려고

## 5. 지금까지 나온 숫자 (2026-09-22)

발표·홍보에 쓸 수 있는 실측값.

| | 결과 | 기준 |
|---|---|---|
| 맨얼굴 4장 자동 촬영 | **22.5초**, 재촬영 0회 | 목표 60초 |
| 룩 얹어보기 1장 | **2.55초** (fp16 8스텝) | 목표 3초 |
| 얼굴형 분류 | **81.5% ±0.6** | 기존 규칙 22.2% |
| 자동 검증 | **239개**(브라우저) + **56개**(서버) 전부 통과 | — |

**쓰면 안 되는 숫자**: 얼굴형 **80.8%** 는 데이터 누수로 과대평가된 값이었다. 정정해서 71.7%(CNN), 방법을 바꿔 81.5%(얼굴 점 + MLP + 머리선). **81.5% 만 쓴다.**

> 정정 과정 자체가 좋은 이야기다 — "처음엔 80.8% 였는데 누수를 찾아 71.7% 로 정정하고, 방법을 바꿔 81.5% 로 올렸다" 는 그냥 81.5% 보다 강하다.

**아직 없는 숫자** (있는 척 쓰지 말 것): 채점 정확도(E-1), 실사용자 만족도, 실기기 왕복 시간.

## 6. 우리가 **안 하는 것** — 경계

홍보 문구에서 이 선을 넘으면 안 된다.

| 안 한다 | 왜 |
|---|---|
| **미모 점수** | 우리 점수는 "가이드와 얼마나 맞았나"지 **얼굴 평가가 아니다.** 이걸 흐리면 서비스 성격이 바뀐다 |
| **얼굴 보정 필터** | 예뻐 보이게 만드는 게 아니라 **실제로 잘 바르게** 하는 것 |
| **브랜드 제품 추천** | 광고가 아니다. 제품 **종류**만 |
| 눈 모양별 스타일 추천 | 추천이 아니라 **고른 룩을 따라 하게** 돕는 것 |
| 사진을 서버에 보관 | 룩 생성에만 잠깐 쓰고 **즉시 삭제**한다. 자동 검증이 이걸 지킨다 |

## 7. 말투 규칙

서비스 화면이 지키는 규칙과 같게 간다. 홍보물도 여기 맞춘다.

- **숫자를 들이밀지 않는다.** 화면에 나가는 건 점수와 한 줄 평뿐이다. "3mm 벗어났습니다" 가 아니라 "꼬리가 조금 올라갔어요"
- **정직하다.** 못 잰 건 점수를 지어내지 않고 "확인만" 이라고 한다. 홍보도 마찬가지 — 아직 안 된 걸 된 것처럼 쓰지 않는다
- **가르치는 말투지 평가하는 말투가 아니다.** "틀렸습니다" 가 아니라 "여기를 조금 더"
- 존댓말, 짧은 문장

## 8. 개인정보 — 홍보물에서 특히 조심

- **사진은 기기 안에 있다.** 서버로 가는 건 룩 생성 하나뿐이고 끝나면 즉시 지운다
- 얼굴형 판정·가이드·채점은 **전부 폰에서** 돈다
- **남의 얼굴 사진을 쓰지 않는다.** 연예인 사진(저작권+퍼블리시티권), 무료 스톡(모델 릴리스 미검증), 연구용 데이터셋 전부 안 된다
- 홍보물에 얼굴이 필요하면 **AI 생성 얼굴**(초상권 없음)이나 **동의서 받은 팀원**만

## 9. 상태 — 정직하게

**미완성이다.** 2026-09-22 기준 스프린트 1 진행 중, 마감 10/9.

- 여섯 모듈 전부 코드가 돌아감, 자동 검증 통과
- **아직 전 화면이 이어져 있지 않다** (통합은 스프린트 3)
- 실사용자 실험 전
- 얼굴형 CNN 이 아직 앱에 안 들어감 (현재 규칙 22.2%)

홍보물에 "지금 써 보세요" 같은 말을 쓸 수 없다. **"만들고 있습니다"** 가 맞다.
