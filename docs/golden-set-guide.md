# 골든 세트 만들기 — ⑤ 용 설명서

2026-09-30 · ③·⑥ 작성 · 관련 이슈 #58(동의·촬영) · #59(골든 30장) · #64(사람 판정) · #38(채점 일치율) · #44(기준값 확정)

## 왜 필요한가 — 학습이 아니라 "기준값 맞추기와 정확도 재기"

채점은 **학습한 모델이 아니라 규칙**이다. 맨얼굴과 화장 사진의 같은 자리 색을 비교해서, 가이드 선 안을 얼마나 채웠고 밖으로 얼마나 나갔는지 잰다. 이 규칙 안에 숫자가 20개쯤 있는데(색 차이 14, 넘침 30%, 조명 20 …) 지금은 **전부 가정값**이다.

골든 세트는 **실사진 + 사람 정답**이다. 이걸로

- 채점이 사람 판정과 **몇 % 맞는지** 잰다 — 발표에 쓰는 숫자 (#38)
- 가정값을 사람 판정과 가장 잘 맞는 값으로 **확정**한다 (#44)
- 채점을 고칠 때마다 다시 돌려서 **나빠지지 않았는지** 본다

학습이 아니라서 **수천 장이 필요 없다.** 계획은 30장(6명 × 5장)이지만, **팀원 2~3명으로 먼저 시작**해도 가정값이 크게 틀렸는지는 알 수 있다.

## 1. 동의와 사진 보관

- 찍는 사람 모두에게 **동의**를 받는다 (#58 양식). 평가·발표에 쓰고, 학습에는 쓰지 않는다
- 사진은 **저장소에 넣지 않는다.** `$DHE_DATA_DIR`(각자 PC 의 저장소 밖 폴더)에만 둔다
- 사람 이름 대신 **`p01`, `p02` …** 번호를 쓴다 (결과 표에 이 번호가 남는다)

## 2. 찍는 법

한 사람에 대해:

1. **맨얼굴 정면 한 장** (`bare`) — 화장 전, 정면, 무표정, 앞머리가 이마·눈썹을 가리지 않게
2. **부위마다 화장한 사진** — 같은 자리·같은 조명·같은 거리에서 정면으로. 부위 하나를 그리고 찍고, 다음 부위를 그리고 찍는다
3. **일부러 틀리게 그린 사진도 섞는다** — 선 밖으로 넘치게, 한쪽만 짧게, 입술 선 밖으로 등. 정답이 전부 "맞음" 이면 채점기가 틀리게 그린 걸 잡는지 알 수 없다. 대략 **맞음·조금·많이가 비슷하게** 나오도록

주의

- **같은 자리·같은 조명**이 제일 중요하다 (채점은 맨얼굴과 색을 비교한다). 창가라면 시간을 크게 띄우지 않는다
- 폰 전면 카메라, 얼굴이 화면 절반쯤. 흔들리지 않게
- 부위: `brow` 눈썹 · `liner` 아이라이너 · `lip` 입술 · `shadow` 섀도우 · `cheek` 볼터치 (쉐딩은 앱에서 항상 "확인만" 이라 뺀다)

## 3. 폴더와 파일 이름

```
$DHE_DATA_DIR/golden/raw/
  p01/
    bare.jpg                 맨얼굴 (꼭 하나)
    liner_smoky.jpg          <부위>_<화장>.jpg   — 화장은 rules/looks.json 의 id (daily·smoky…)
    liner_smoky_off.jpg      <부위>_<화장>_<메모>.jpg — 같은 부위를 여러 장 찍을 때 (메모는 아무 말)
    lip.jpg                  화장 이름을 모르면 빼도 됨 (채점기가 기본 화장으로 잰다)
  p02/
    ...
```

JPG·PNG 둘 다 된다. 폰 사진의 회전 정보는 도구가 알아서 반영한다.

## 4. 시험지 만들기

```
uv run --extra eval python eval/golden/build.py
```

- 사진을 PNG 로 바꾸고, **얼굴 점 478개**를 뽑고(앱과 같은 모델), 사진 지문을 계산해서 `eval/golden/manifest.json` 에 시험지를 쓴다 (사진은 안 들어가고 경로·지문·라벨만)
- **라벨 표** `$DHE_DATA_DIR/golden/labels.csv` 를 만든다
- 얼굴을 못 찾은 사진, 이름이 틀린 사진, 맨얼굴이 없는 사람은 알려 주고 건너뛴다

## 5. 라벨 매기기 (#64)

`labels.csv` 를 엑셀·구글 시트로 열어 **두 사람이 따로** 채운다 (서로 안 보고).

| 칸 | 누가 | 값 |
|---|---|---|
| `a` | 라벨러 1 | `ok` / `slight` / `off` |
| `b` | 라벨러 2 | `ok` / `slight` / `off` |
| `final` | 둘이 상의 | a·b 가 다를 때만 |

기준 — **앱이 보여 주는 가이드(테두리) 기준으로**, 맨얼굴 사진과 나란히 놓고 본다

| 값 | 뜻 | 예 |
|---|---|---|
| `ok` 맞음 | 가이드 안을 잘 채웠고 거의 안 넘침 | 라이너가 속눈썹 선을 따라 끊김 없이, 꼬리 길이도 비슷 |
| `slight` 조금 | 조금 넘치거나 조금 비었음 — 고치면 금방 됨 | 입술 선이 한쪽만 1~2mm 밖, 눈썹 꼬리가 조금 짧음 |
| `off` 많이 | 확실히 넘치거나 많이 비었거나 모양이 다름 | 라이너가 두 배 두께, 볼터치가 광대 밖, 한쪽 눈썹만 그림 |

한 장에 1분 안쪽. 다 채우면 **다시 돌린다** — 라벨이 시험지에 합쳐진다 (적어 둔 라벨은 지워지지 않는다).

```
uv run --extra eval python eval/golden/build.py            # 라벨 합치기
uv run --extra eval python eval/golden/build.py --check    # 빠진 사진·바뀐 사진·잘못된 라벨 검사
```

## 6. 채점 돌리기 (③)

```
uv run --extra eval python eval/score/run.py
```

사람 정답 vs 채점기 — 정답률, 위험한 오답(사람은 "많이" 인데 채점기는 "맞음"), 확인만 비율, 사람끼리 일치율(카파)이 `eval/results/` 에 나온다. 여기서부터 ③ 이 기준값을 맞춘다.

## 먼저 작게 — 추천

1. 팀원 **2~3명**, 부위 **2~3개**(라이너·입술·볼터치), 사람마다 맞음·조금·많이 한 장씩 → 20~30장
2. 위 4~6 을 한 번 끝까지 돌려서 **도구·찍는 법에 문제가 없는지** 본다
3. 괜찮으면 계획대로 6명 × 5장으로 늘린다 (같은 도구, 숫자만 바뀜)
