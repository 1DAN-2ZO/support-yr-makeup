# 촬영·사진 이용 동의서 (v1, 2026-09-18)

당화응 촬영 세션(데이터 계획 A-2·A-3, 분업 5-1)에서 받는 서면 동의서다.
인쇄용 A4 한 장 판은 `docs/consent-form-v1.html`, 만드는 법은 이 문서 맨 아래.

---

## 1. 왜 서면 동의가 필요한가

- 얼굴 사진은 개인정보이고, 얼굴 특징으로 사람을 구분하는 데 쓰면 **생체인식정보**로 다뤄진다. 개인정보보호법은 이 경우 다른 개인정보와 **따로 동의**를 받도록 한다.
- 우리는 사진을 **평가(시험지)** 뿐 아니라 **얼굴형 모델 학습**과 **발표 자료**에도 쓴다. 쓰는 범위가 넓을수록 동의서에 그대로 적혀 있어야 한다.
- 데이터 계획에도 자체 촬영은 서면 동의서가 필수로 적혀 있다 (`data-needs-v6.md` 139줄).

## 2. 동의 구조 — 필수 1개, 선택 3개

촬영에 필요한 것만 필수로 두고, 공개 범위는 선택으로 나눈다. 선택에 동의하지 않아도 촬영에 참여할 수 있다.

| 구분 | 항목 | 쓰는 곳 |
| --- | --- | --- |
| **필수** | 앱 개발과 성능 검증 (팀 내부) | 채점 정확도 측정, 촬영·게이트 검증 |
| 선택 ① | 얼굴형 분류 모델 학습 | 모델 가중치에 반영 |
| 선택 ② | 발표 자료·보고서에 사진 게재 | 최종 발표, 과제 보고서 |
| 선택 ③ | 앱 화면의 예시 이미지로 사용 | 시연 화면 |

선택 ①은 거절하면 그 사람 사진을 학습에서 뺀다. 선택 ②·③은 거절하면 화면에 얼굴이 나오지 않게 한다.

## 3. 동의서에 반드시 들어간 내용

- **수집 항목**: 얼굴 사진(맨얼굴·부위별 화장 단계), 촬영 조건 기록(조명·각도), 얼굴형·부위 판정 라벨, 이름과 서명
- **보관 장소**: 팀이 정한 로컬 폴더(`DHE_DATA_DIR`). 원본은 GitHub 저장소에 올리지 않는다
- **식별 정보 분리**: 파일 이름은 `person_01` 같은 익명 번호를 쓰고, 이름과 번호를 잇는 표는 따로 보관한다
- **보관 기간**: 프로젝트 종료 후 30일 이내 파기
- **파기 예외**: 이미 학습이 끝난 모델 가중치에는 사진이 복원 불가능한 형태로 남는다. 삭제를 요청하면 다음 학습부터 그 사람 사진을 빼고 다시 학습한다
- **제3자 제공**: 없음. 외부 AI 서비스나 공개 데이터셋에 올리지 않는다
- **철회**: 언제든 말이나 문자로 요청하면 지운다. 철회해도 불이익이 없다
- **연령**: 만 14세 이상만 참여

## 4. 촬영 당일 진행 방법

1. 동의서를 읽고 서명받는다. 선택 항목은 본인이 직접 체크하게 한다.
2. 서명한 동의서를 사진으로 찍어 `DHE_DATA_DIR/consent/`에 `person_01_consent.jpg`로 저장한다. 종이는 팀장이 보관한다.
3. 참가자 번호를 정하고, 이름–번호 표(`participants.csv`)에 적는다. 이 표는 저장소에 넣지 않는다.
4. 촬영을 시작한다.

## 6. 남은 확인

- 보관 책임자는 **전지원**(⑤ 모델·데이터·평가 담당)으로 넣었다. 연락처 칸은 인쇄 후 손으로 적거나, 정해지면 HTML에서 채운다.
- 프로젝트 종료일이 정해지면 "파기 시점"에 날짜를 적는다.
