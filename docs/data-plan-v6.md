>
> **쉽게 말하면** 당화응은 "네 맨얼굴 사진을 기준으로, 네가 그린 화장이 가이드랑 얼마나 맞는지" 봐 주는 앱이다. **가이드는 우리가 네 얼굴에 맞춰 그려 주니까 정답은 이미 우리 손에 있다.** 그래서 필요한 재료는 세 종류다. ① **시험지**: 우리가 만든 게 진짜 얼굴에서도 맞는지 확인할 사진(검증·평가). 가장 급함. ② **연습 문제**: 얼굴형 모델을 가르칠 사진(학습). 많지 않다. ③ **화면에 보여줄 것**: 룩 사진·문구·제품 목록(콘텐츠). 룩 사진은 얹어보기 AI 의 재료이기도 하다. 남의 사진은 대부분 "연구용으로만"이라, 앱 화면에 띄우거나 학습에 쓰려면 우리가 직접 찍거나 합성 얼굴을 써야 한다.
>
> 상태: **있음** = 이미 확보 · **후보** = 받아올 데이터가 있음(2부) · **미정** = 출처 없음 · **자체** = 우리가 찍거나 만든다 · **보류** = 나중에 우리가 정함.

**왜 정답 데이터셋이 필요 없는가 (4차)**: 사용자가 룩을 고르면 우리가 그 사람 랜드마크에 맞춰 가이드(테두리·밴드)를 계산해 그려 준다. 채점은 "사용자가 그린 것"과 "우리가 그려 준 것"의 비교이므로, 정답은 항상 우리 손에 있다. 남의 사진에서 정답을 찾을 필요가 없다. 필요한 건 **그 비교가 실제 사진에서도 맞는지 확인할 시험지(A)** 뿐이다.

**발표에 나가야 할 숫자 3개** (이 문서의 목적): ① 실사진 200장에서 채점기 판정과 사람 판정의 일치율(A-2) ② 얼굴형 규칙 정확도 → 모델 정확도, 라벨러 간 일치율(B-1) ③ 화장 전이 1장 시간·정체성 유지 점수·룩 색 반영도(C-1).

**1주차에 반드시 시작해야 하는 것**은 ★ 표시.

## 1주차에 시작할 것 (★)

1. **A-2·A-3 한 번의 촬영 세션으로** — 20명 × 10장, 같은 자리에서 맨얼굴 → 눈썹 → 라이너 → 섀도우 → 립 → 볼터치 단계별 촬영, 일부러 벗어난 장 포함, 조명 3종·각도 3종. 촬영 프로토콜과 **서면 동의서(촬영·라벨·앱 화면 사용)**를 먼저. 찍은 뒤 **부위별 사람 판정(3단계)** 과 **얼굴형 2인 라벨(B-1)** 을 붙인다. 픽셀 라벨은 안 한다.
2. **D-1 룩 참조 이미지 방법 결정** (자체 촬영 / 생성 / Generated Photos 구매). C-1 평가와 B-2 LoRA 가 여기 걸려 있다.
3. **B-1 얼굴형 분류기 시작** — Kaggle Face Shape 내려받아 1차 학습, 그 전에 C-4 규칙 정확도 기준선을 자체 라벨로 먼저 잰다.
4. **AI Hub 3종 신청** (한국인 안면, 글로벌 피부색, 한국인 피부상태). EasyPortrait 내려받아 C-3 영역 겹침 평가.
5. **C-1** — 참조 사진이 생기면 서버 화장 전이를 A-2 맨얼굴 20명으로 돌려 정체성·색 반영도 측정.

## 라이선스 한 줄 규칙
- 화면에 띄우는 사진(D-1)과 학습에 넣는 사진(B)은 **비상업 데이터셋 불가**. 평가·참고(C)는 가능.
- Kaggle Face Shape(라이선스·라벨 근거 불명)는 **1차 학습·실험까지만**. 최종 가중치는 자체 라벨(동의서)·AI Hub(학습 허용)로 다듬는다.
- AI Hub 데이터는 학습에만 쓰고 화면 게시·재배포 금지.
- 자체 촬영은 **서면 동의서**(사용 범위: 발표·학습·라벨·앱 화면) 필수. 양식을 1주차에 만든다.
- 최종 판단은 `datasets-ranked-v6.md`(jeakeun, 실측 기반)가 우선한다. 이 문서는 "무엇이 필요한가"의 목록.

### 1-1. 얼굴형 분류기 학습·검증 (B-1·C-4) — 우리가 학습하는 유일한 필수 모델

> **쉽게 말하면** 얼굴형 모델의 교재와 시험지. 사람이 "이 얼굴은 둥근형" 하고 적어 둔 연예인 사진 5,000장으로 처음 배우게 하고(누가 어떻게 적었는지 몰라서 여기까지만), 팀원 셀피 50~100장에 우리가 직접 얼굴형을 적어 한국인 얼굴에 맞게 다듬고 최종 점수를 낸다. 두 사람이 따로 적어서 서로 얼마나 같은지도 기록한다.

**1순위: Kaggle Face Shape 로 1차 학습 + 자체 라벨로 다듬기·평가** — 팀원·지인 **50~100명**(A-2 촬영 사진 재사용)에 얼굴형 5종(계란·둥근·각진·긴·하트)을 **팀원 2명이 독립으로** 표시, 불일치는 3인 판정, 라벨러 간 일치율(κ)을 기록한다. 학습 **전에** 현행 규칙(랜드마크 비율)의 정확도를 같은 라벨로 먼저 재 둔다(C-4 기준선). 공개 셋은 전부 서양 연예인 스크랩이고 라벨 근거·라이선스가 불명이라 **1차 학습·실험까지만** 쓰고, 최종 가중치는 자체 라벨과 AI Hub(학습 허용)로 파인튜닝한다. 발표 숫자: 규칙 정확도 → 모델 정확도, 라벨러 일치율(상한).
