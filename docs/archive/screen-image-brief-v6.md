## A. 공통 규칙 (모든 이미지)

**프레임**
- 모바일 브라우저 화면 한 장(지금은 웹, 앱은 이후). 기본은 세로, 비율 9:19.5 (1080×2340). **화면 3·4·5(눈썹·눈 단계)는 가로 19.5:9 (2340×1080)** — 양쪽 눈을 한 화면에 담기 위해 폰을 눕힌 상태. 폰 베젤 없이 화면만, 또는 얇은 검은 베젤.
- 진행 칩 6개(눈썹 · 아이라이너 · 섀도우 · 입술 · 볼터치 · 쉐딩·하이라이트)는 화면 3~5 상단에 항상 있고, 누르면 그 단계로 이동한다는 뜻으로 칩마다 상태(✓ 완료 / 진행 중 / 확인만 / 건너뜀 / 미시작)를 표시.
- 상단 상태바(시간 9:41, 배터리)는 있어도 되고 없어도 됨. 브랜드 로고·제조사 표시 없음.

**스타일**
- 따뜻한 중성톤 UI. 배경 #F7F5F1, 카드 흰색, 본문 글자 #2B2B2B, 보조 글자 #6B6B6B.
- 강조색 청록 #2A8C85 (다음·버튼), 주의 주황 #C2731F (경고), 오류 붉은색 #B8432F (경고 문구에만, 사진 위 표시 없음).
- 산세리프 글꼴, 굵기 2단계만. 그림자 최소, 모서리 둥글게 12px.
- 사진 위 오버레이는 얇은 선(2px)과 점선만. 면 채우기 없음.
- 실사 사진처럼 보이는 얼굴 위에 UI가 얹힌 형태. 일러스트·만화체 아님.

**얼굴 모델 (모든 화면에서 같은 사람)**
- 20대 중반 성인 한 명, 정면 셀카 구도, 어깨까지. 맨얼굴에 가까운 상태에서 시작해 화면이 진행될수록 해당 부위만 화장이 추가됨.
- 실내 자연광, 흰 벽 배경. 안경·모자·앞머리로 눈썹 가림 없음.
- 특정 성별을 강조하는 스타일링 없음(중성적 머리 길이, 무채색 상의).

**텍스트**
- 화면 안 문구는 "화면별 지시"의 문구를 **그대로** 쓴다. 숫자도 바꾸지 않는다.
- 이미지 모델이 한글을 깨뜨리면: (1) 영문 라벨 버전(각 화면에 병기)으로 먼저 뽑고, (2) 한글은 나중에 편집으로 얹는다.

**절대 넣지 않는 것**
- 3D 얼굴 모델, 메시, 아바타, 와이어프레임 얼굴
- 브랜드 로고, 상품명, 가격, 구매 버튼
- 음성·스피커 아이콘, 마이크
- "AI가 자동으로 채점 중" 같은 자동 채점 표현. 채점은 사용자가 버튼을 누른 뒤에만
- 피부 진단 문구(모공, 주름, 트러블)
- 그라데이션 균일도, 들뜸, 절대 강도 점수
- 결과 화면(4·5)에 거리·각도·% 같은 숫자 라벨

## B. 화면별 지시

각 화면은 "목적 / 위에서 아래로 레이아웃 / 오버레이 / 화면 문구 / 영문 라벨"로 적는다.

### 화면 1. 맨얼굴 촬영
- 목적: 세션 시작. 4장(정면 눈 뜸·눈 감음, 좌·우 45°)을 자동으로 찍는 중. 셔터 버튼 없음.
- 변형 1-a (선택): 촬영 직전 동의 화면. 문구 "사진 3장을 서버로 보내 화장 미리보기와 쉐딩 위치를 만듭니다. 처리 후 바로 삭제됩니다." 버튼 "동의하고 시작" / "동의하지 않음". 거부하면 "서버 처리에 동의해야 사용할 수 있어요" 안내. 영문 "Agree and start" / "Don't agree".
- 변형 1-b (선택): 4장 완료 화면. 썸네일 4개(정면 뜸·정면 감음·좌·우) + 각 썸네일 아래 "다시 찍기" 작은 버튼 + 하단 "룩 고르러 가기". 영문 "Retake" / "Choose a look".
- 레이아웃: 전체 화면 전면 카메라 프리뷰(맨얼굴). 화면 중앙에 얼굴 크기의 타원 가이드(점선). 상단 얇은 안내 바, 하단 진행 표시 4칸 중 1칸 채워짐.
- 오버레이: 타원 점선 청록. 눈 위치에 작은 십자 두 개. 칩 없음. 조건이 안 맞으면 타원 아래 한 줄만("조금 더 밝은 곳으로").
- 화면 문구: 상단 "정면을 보고 눈을 뜨세요" / 하단 "1 / 4 · 다음: 눈 감기 → 왼쪽 45° → 오른쪽 45°" / 조건 안내 한 줄 "조금 더 밝은 곳으로"(안 맞을 때만)
- 영문 라벨: "Look straight, eyes open" / "1 / 4 · Next: close eyes → left 45° → right 45°" / "Find a brighter spot"

### 화면 2. 룩 얹어보기 + 제품 목록
- 목적: 룩을 내 얼굴에 입혀 보고, 쓰이는 제품 종류를 보고 고른다.
- 레이아웃: 상단 절반은 전면 카메라 실시간 프리뷰에 "스모키" 룩이 입혀진 모습(눈가 어둡게, 볼 핑크, 입술 MLBB). 고개가 살짝 왼쪽으로 돌아가 있어도 화장이 얼굴에 붙어 있음. 모서리에 작은 "LIVE" 칩. 그 아래 가로 스크롤 썸네일 10개 중 5개 보임(데일리 정돈 / 면접 / 스모키(선택됨) / 음영 강조 / 코랄 … ), 뒤쪽 2개는 회색 스피너와 "로딩 중". 그 아래 카드 "이 룩에 쓰인 것" 목록 4줄 전부 펼침(접기 없음). 하단 큰 버튼.
- 오버레이: 화장 레이어 자체가 오버레이(선·점선 없음). "LIVE" 칩, 썸네일 중 선택된 것에 청록 테두리.
- 화면 문구: 카드 제목 "이 룩에 쓰인 것" / 목록 "눈 · 다크 브라운 섀도우 (매트)" "눈 · 블랙 젤 라이너" "볼 · 핑크 파우더 블러셔" "입술 · MLBB 립" / 로딩 썸네일 "로딩 중" / 버튼 "이 룩으로 시작" (근거 한 줄은 이 화면에 없음, 화면 2-b로)
- 영문 라벨: "Used in this look" / "Eyes · Dark brown shadow (matte)" "Eyes · Black gel liner" "Cheeks · Pink powder blush" "Lips · MLBB lipstick" / "Loading" / "Start with this look"
- 변형 2-a (선택): 진입 직후, 모든 썸네일이 "로딩 중"이고 프리뷰는 맨얼굴만. 상단 문구 "미리보기를 만드는 중이에요 (약 30초)". 영문 "Preparing previews (~30s)".

### 화면 2-b. 전체 완성 예상 (렌더링 한 장)
- 목적: 룩 확정 직후, 이 룩을 다 하면 내 얼굴이 어떻게 되는지 한 장으로 보여준다.
- 레이아웃: 세로 화면. 화면 대부분은 내 정면 사진에 "스모키" 룩 전체가 입혀진 정지 렌더링(눈·볼·입술 모두). 위에 작은 회색 칩 "완성 예상". 하단 큰 버튼 "시작". 멘트 없음.
- 오버레이: 없음. 렌더링 자체가 내용.
- 화면 문구: 칩 "완성 예상" / 버튼 "시작"
- 영문 라벨: "Expected result" / "Start"

### 화면 3. 부위 완성본 (아이라이너, 가로 모드)
- 목적: 이 부위가 다 되면 어떤 모습인지 먼저 보여준다. 정지 이미지.
- 레이아웃: **가로 화면**. 왼쪽 상단 진행 칩 6개 중 2번째 활성(눈썹 ✓ · 아이라이너 · 섀도우 · 입술 · 볼터치 · 쉐딩·하이라이트). 화면 대부분은 전체 완성 예상 렌더링(화면 2-b)을 양쪽 눈으로 줌한 모습(다른 부위도 화장된 채). 오른쪽 세로 카드: 근거 한 줄, "지금 필요한 것", 버튼 "그리러 가기".
- 오버레이: 없음. 완성본 이미지 자체가 내용. 카드 위에 작은 회색 칩 "완성본".
- 화면 문구: 제목 "아이라이너 · 완성본" / 근거 "눈꼬리를 살짝 올려 짧게 빼세요. 양쪽 꼬리 높이를 맞추세요" (숫자 없음) / 필요한 것 "지금 필요한 것: 블랙 젤 라이너 + 각진 브러시" / 버튼 "그리러 가기"
- 영문 라벨: "Eyeliner · Finished look" / "Match both wing heights" / "Now you need: Black gel liner + angled brush" / "Go draw"
- 변형 3-b (선택): 이 화면에 들어가기 직전 세로 화면에 뜨는 안내. 폰을 눕히는 아이콘과 문구 "눈 단계는 양쪽 눈을 같이 봐요. 폰을 가로로 돌리세요". 영문 "Turn your phone sideways to see both eyes".
- 변형 3-d (선택): 눈 단계가 끝나고 입술 단계로 넘어갈 때 가로 화면에 뜨는 안내. 폰을 세우는 아이콘과 문구 "이제 폰을 세로로 돌리세요". 영문 "Turn your phone upright".
- 참고: 완성본은 전체 완성 예상 렌더링을 줌한 것이라 눈썹·섀도우도 화장된 채로 보인다. 별도 합성 없음.

### 화면 4. 실시간 테두리 (아이라이너, 가로 모드)
- 목적: 그릴 자리 테두리가 실시간으로 얼굴을 따라간다. 거울에서 돌아오면 이 화면이 그대로 있고, 얼굴이 잡히면 "확인받기"가 활성화된다. 채점은 버튼을 눌러야만.
- 레이아웃: **가로 화면**. 실시간 프리뷰가 **화면 전체**를 채움(양쪽 눈을 눈 바깥 끝에서 끝까지 2배 확대, 맨눈, 아직 라이너 없음). 카드·사이드바 없음. 왼쪽 상단에 진행 칩(반투명), 상단 가운데 얇은 상태 줄에 품질 게이트 한 줄만: 다 맞으면 "확인받을 준비 됨", 안 맞으면 안 맞는 조건 하나만 ("조금만 정면으로"). **오른쪽 아래 구석에 작은 원형 버튼 "확인받기"**(활성, 누르면 즉시 촬영). "지금 필요한 것" 없음(화면 3에서 봄). 자리 비움 문구 없음. 건너뛰기 버튼 없음. 왼쪽 아래 구석에 작은 "LIVE" 칩.
- 오버레이: 양쪽 눈 위 눈꺼풀 속눈썹 선을 따라 청록 **테두리(점선)**, 양쪽 눈꼬리에서 바깥 위로 올라가는 꼬리 선. 두 눈 사이에 옅은 수평 기준선. **면 채우기 없음, 선만.** 각도·mm 라벨 없음.
- 화면 문구: 상태 줄 "확인받을 준비 됨" / 구석 버튼 "확인받기" (제목·제품 안내·자리 비움·건너뛰기 문구 없음)
- 영문 라벨: "Ready to check" / "Check"
- 변형 4-b (선택): 같은 화면인데 손이 눈을 가리고 있고 상태 줄이 "손을 내려 주세요" 한 줄, 구석 버튼 회색 비활성. 영문 "Lower your hand".
- 변형 4-c (선택): 돌아온 뒤, 양쪽 눈에 라이너가 그려진 상태로 같은 화면. 테두리는 옅게 유지.

### 화면 5. 부위 결과 (아이라이너, 가로 모드)
- 목적: 확인받기 결과. 점수, 내가 한 화장 위에 가이드 테두리 겹침, 한 줄 평. **숫자(거리·각도·%)는 없음.**
- 레이아웃: **가로 화면**. 왼쪽 2/3는 양쪽 눈 확대 사진(라이너 그려짐). 오른쪽 1/3 카드: 큰 숫자 점수, 한 줄 평, 버튼 3개(다음 청록 / 다시 확인받기 흰색 테두리 / 건너뛰기 회색 텍스트). 점수가 낮아도 "다음"은 활성. 마지막 부위(쉐딩·하이라이트)에서는 "다음" 대신 "결과 보러 가기".
- 오버레이: 사진 위에 가이드 **테두리(청록 점선)**만. 어긋난 곳 표시(점·화살표·체크) 없음, 라벨·숫자 없음.
- 화면 문구: 점수 "82" 작은 글자 "/ 100" / 한 줄 평 "오른쪽 꼬리가 조금 위로 갔어요. 왼쪽에 맞춰 살짝 내려 그리세요" / 버튼 "다음" "다시 확인받기" "건너뛰기"
- 영문 라벨: "82 / 100" / "Right wing is a bit high. Bring it down to match the left" / "Next" "Check again" "Skip"
- 참고: "다시 확인받기"는 화면 4(실시간 테두리)로 돌아간다. 완성본(화면 3)부터 다시 보려면 진행 칩에서 그 부위를 누른다.

### 화면 3-c. 쉐딩·하이라이트 완성본 (세로 모드)
- 목적: 마지막 단계. 쉐딩·하이라이트는 룩 렌더링에 없으므로 완성본 대신 **얼굴형 규칙으로 정한 자리를 테두리로** 보여준다. 색 면 채우기 없음.
- 레이아웃: 세로 화면. 상단 진행 칩 6개 중 6번째 활성(앞 5개는 ✓). 화면 대부분은 전체 완성 예상 렌더링(화면 2-b)을 얼굴 아래쪽(광대~턱)으로 줌한 정지 이미지. 그 위에 규칙 자리 테두리. 아래 카드: 얼굴형 멘트 한 줄, "지금 필요한 것", 버튼 "그리러 가기". 카드 위 작은 회색 칩 "완성본".
- 오버레이: **테두리만.** 양쪽 광대 아래에서 턱선을 따라가는 쉐딩 영역 윤곽(청록 점선, 안쪽 비움), 광대 위·콧대·이마 가운데 하이라이트 영역 윤곽(옅은 청록 점선). 두 종류를 구분하는 작은 라벨 "쉐딩" "하이라이트"만, 숫자 없음.
- 화면 문구: 제목 "쉐딩·하이라이트 · 완성본" / 멘트 "둥근 얼굴형이라 턱선과 광대 아래에 쉐딩을, 광대 위에 하이라이트를 넣었어요" / 필요한 것 "지금 필요한 것: 컨투어 파우더 + 하이라이터 + 브러시" / 버튼 "그리러 가기"
- 영문 라벨: "Contour · Highlight · Finished look" / "Your face is round, so contour goes along the jaw and under the cheekbone, highlight above it" / "Now you need: Contour powder + highlighter + brush" / "Go draw"
- 참고: 화면 4(실시간)로 넘어가면 같은 테두리가 라이브 화면 전체에 얼굴을 따라 뜬다. 세로 모드.

### 화면 5-b. 쉐딩·하이라이트 결과 (세로 모드, 확인만)
- 목적: 쉐딩·하이라이트는 점수를 매기지 않는다. 내 화장 위에 규칙 테두리를 겹쳐 보여주고 "확인하고 넘어가세요".
- 레이아웃: 세로 화면. 상단 2/3는 확인받기 프레임(얼굴 아래쪽 확대, 쉐딩·하이라이트 발린 상태). 아래 카드: 점수 자리에 큰 글자 대신 회색 칩 "확인만", 한 줄 평, 버튼 3개("결과 보러 가기" 청록 — 마지막 부위이므로 "다음" 대신 / 다시 확인받기 흰색 테두리 / 건너뛰기 회색 텍스트).
- 오버레이: 사진 위에 화면 3-c와 같은 규칙 테두리(청록 점선)만. 면 채우기·점·화살표·숫자 없음.
- 화면 문구: 칩 "확인만" / 한 줄 평 "확인하고 넘어가세요. 오른쪽이 조금 진해요" / 버튼 "결과 보러 가기" "다시 확인받기" "건너뛰기"
- 영문 라벨: "Check only" / "Check and move on. Right side is a bit darker" / "See results" "Check again" "Skip"
- 변형 5-b-1 (선택): 좌우 차이가 없을 때 한 줄 평 "확인하고 넘어가세요". 영문 "Check and move on".

### 화면 6. 전체 리뷰 (합산 점수)
- 목적: 세션 끝. 부위별 점수와 합산, 쌩얼 vs 내 화장.
- 레이아웃: 세로 화면. 상단 큰 숫자 합산 카드(숫자만, 기준 표기 없음). 그 아래 가로 막대 6줄(부위명, 점수 또는 "확인만", 결과 화면의 한 줄 평 그대로). 그 아래 좌우 나란히 사진 두 장(왼쪽 "쌩얼", 오른쪽 "내 화장", 같은 크롭·같은 크기). 하단 버튼 두 개(결과 저장 / 끝내기).
- 오버레이: 없음.
- 화면 문구: 합산 "78" "/ 100" / 막대 "눈썹 88 · 좌우가 잘 맞아요" "아이라이너 82 · 오른쪽 꼬리가 조금 위로" "섀도우 · 확인만 · 색이 옅어서 재지 못했어요" "입술 79 · 아래 경계가 살짝 밖으로" "볼터치 71 · 오른쪽이 진해요" "쉐딩·하이라이트 · 확인만" / 사진 라벨 "쌩얼" "내 화장" / 버튼 "결과 저장" "끝내기"
- 영문 라벨: "78 / 100" / "Brows 88" "Eyeliner 82" "Shadow · check only" "Lips 79" "Blush 71" "Contour·Highlight · check only" / "Bare face" "My makeup" / "Save result" "Finish"

### (선택) 화면 0. 한 장 스토리보드
- 위 1·2·2-b·3·4·5·6 일곱 화면을 가로 한 줄로 배치한 16:9 이미지. 각 화면 아래 짧은 캡션(촬영 → 룩 선택 → 완성 예상 → 완성본 → 실시간 테두리 → 부위 결과 → 전체 리뷰). 발표 슬라이드용.

## C. 요청 문장 (복사해서 화면 번호만 바꿈)

```
위 문서의 A. 공통 규칙을 모두 지켜서, B. 화면 [3]을 모바일 브라우저 화면 이미지 한 장으로 만들어 줘.
- 세로 9:19.5(화면 3·4·5의 눈·눈썹 단계는 가로 19.5:9), 실사 얼굴 위에 UI가 얹힌 목업.
- 화면 문구는 적힌 그대로, 숫자 바꾸지 말 것. 한글이 깨지면 영문 라벨 버전으로.
- A의 "절대 넣지 않는 것" 목록은 넣지 말 것 (3D 얼굴, 브랜드, 음성 아이콘, 자동 채점 표현, 피부 진단).
- 같은 얼굴 모델을 다른 화면에서도 쓸 수 있게 정면 셀카 구도, 실내 자연광, 흰 벽.
```

여러 장을 한 번에 받을 때:

```
B. 화면 1, 2, 2-b, 3, 4, 5, 6을 같은 얼굴·같은 스타일로 각각 한 장씩, 총 7장 만들어 줘. 공통 규칙 A 적용.
```
