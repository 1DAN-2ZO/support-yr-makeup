A. 개발·검증용 사진 — 촬영·정렬·채점이 실제 얼굴로 되는지

쉽게 말하면 지금 POC는 "컴퓨터가 그린 가짜 화장"으로만 시험을 봤다. 진짜 사람이 진짜로 그린 화장 사진이 있어야 채점기가 실제로 맞는지 안다. 그리고 집 조명·고개 각도·손이 가리는 상황에서도 버티는지 봐야 한다.
#데이터무엇 · 얼마나쓰는 기능상태어디서

B. 학습 데이터 — 직접 학습하는 유일한 모델(화장 영역 분할)

쉽게 말하면 우리가 가르치는 모델은 딱 하나, "사진에서 화장 발린 곳만 오려내기"다. 가르치려면 "정답이 표시된 사진"이 수천 장 필요한데, 사람이 일일이 칠하는 대신 컴퓨터가 맨얼굴 위에 화장을 그려 넣으면서 정답도 같이 만드는 생성기(B-1)가 이미 있다. 이제 그 생성기에 넣을 깨끗한 맨얼굴 사진(B-2)만 있으면 된다.
#데이터무엇 · 얼마나쓰는 기능상태어디서
B-1합성 학습 데이터 생성기맨얼굴 + 절차적 화장 + 정답 마스크(6클래스). 시드 재현, JS·Python 동일, 0차 학습 mIoU 0.899분할 모델 학습(F-08). 생성기이지 데이터가 아님 → B-2 필요있음jeakeun 브랜치 poc/synth

C. 모델 평가 — 공개 모델이 우리 조건에서 되는지

쉽게 말하면 얼굴 부위 나누기, 화장 얹어보기, 얼굴형 판단은 남이 만든 모델이나 우리 규칙을 쓴다. "우리 사진에서도 잘 되나"를 재려면 정답이 붙은 사진이 필요하다. 이건 남의 데이터를 써도 된다. 시험지로만 쓰지 가르치는 데 안 쓰기 때문이다.
