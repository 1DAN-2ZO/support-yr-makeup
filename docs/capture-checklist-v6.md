## 1-4. 4장 연속 촬영 시 이마 L*·a*·b* 변동 폭 (조명 3종 × 3명)

`client/src/core/color.ts` 의 `foreheadLab()` 으로 장마다 재고 `labDrift()` 로 폭을 구한다.

|---|---|---|---|---|---|---|
| 1 | 창가 | | | | | |
| 1 | 실내등 | | | | | |
| 1 | 어두움 | | | | | |
| 2 | 창가 | | | | | |

이 값으로 정하는 것: 게이트 색 조건 임계 `CAPTURE_LIMITS.colorTol`(지금 가정값 6), 채점의 "확인만" 기준(E-5·S-4 근거). 9칸 중 최대 a*b* 폭의 1.5배를 임계로 잡는 것이 출발점.

**(2026-09-23 팀장 우선순위)** 조명(①)은 "안 되면 서비스가 바뀌는" 품질 위험 6개 중 4번이고, **촬영 세션(#58, ⑤)을 기다린다.** 3명 × 조명 3종을 따로 모으지 않고 그 세션에서 같이 잰다.
세션에서 ① 에 필요한 것: 한 사람당 조명 3종(창가·실내등·어두움)마다 `capture-probe.html` 로 4장 한 벌씩. 프로브가 장마다 이마 L*a*b* 를 찍으므로 그 값을 위 표에 옮긴다. (2026-09-27) 끝 버튼을 누르면 결과에 **"1-4 표 한 줄"** 이 나온다 — L*·a*·b* 폭과 정면 눈 뜸 대비 최대 ΔE 가 채워져 있으니 사람·조명 칸만 적어 붙이면 된다. JSON 에는 `labDrift`, 장별 값은 `shots[].at.foreheadL/A/B`.
**이마 급변 = 가림 (2026-09-23 #144)**: 프로브 결과의 `foreheadJump`(300ms 안 이마 ΔE 분포·가림 프레임 수)와 장별 "이마 급변(2초 최대)" 를 같이 본다. 가만히·조명 변화 때의 p99 와 손·브러시·머리카락으로 가렸을 때 값 사이에 `FOREHEAD_JUMP.jumpDE` 를 둔다 → **2026-09-23 iPad 측정으로 20 확정** (가만히 3.0·불 2.8 | 손 63·브러시 44, 앞머리 18.5 는 못 잡음 → 찍기 전 안내). 1-2 study §12-2. 턱·볼 가림을 놓치면 코·턱 참조를 `Baseline` 에 더한다.
같은 조명 세트가 ④ 얹어보기 확인("촬영 때와 조명이 다르면 붕 뜨나")과 ③ 3-9(S-4 색 보정 선정)에도 쓰인다 — 세션 때 한 번에 찍어 공유한다.
