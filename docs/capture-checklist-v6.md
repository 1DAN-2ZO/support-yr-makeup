# 모듈 ① 촬영·기준 — 실기기 측정 표와 체크리스트 (1-2 · 1-3 · 1-4 · 1-11 · 1-12)

코드로 되는 것은 `client/src/core/`·`client/src/screens/` 에 있고, 여기는 **폰이 있어야 채워지는 숫자**를 적는 곳이다.
비어 있는 칸은 아직 안 잰 것. 채운 날짜와 기기를 같이 적는다.

## 준비

| 항목 | 방법 |
|---|---|
| 폰에서 열기 | `cd client && npm run dev -- --host` 뒤 폰에서 `https://<PC IP>:5173` (카메라는 https 필요. `docs/dev-stack-v6.md` mkcert 절) |
| 카메라 잠금 확인 페이지 | `https://<PC IP>:5173/probe-camera.html` — 시작을 누르면 표 한 줄이 나온다 |
| 이벤트 기록 | `capture` 이벤트의 `retry`·`reason` 이 재촬영 횟수와 걸린 조건. 콘솔 또는 내보내기에서 세면 된다 |

|---|---|---|---|---|---|---|

| iPhone (보류 — 아이폰 사용자 있을 때 `probe-lock.html`) | | | | | | |

읽는 법: manual 이 X 인 항목은 그 기기에서 못 잠근다 → 보정(눈 흰자·이마)으로만 막는다. iOS 사파리도 getCapabilities 는 있지만(11+) `exposureMode`·`focusMode` 확장 제약이 없고 `whiteBalanceMode` 만 17.4부터 → **노출 잠금 불가**. Firefox Android 는 셋 다 없음. 기기별 근거·결론은 `docs/study/1-3-camera-locks.md` (2026-09-21 정정).

## 1-10 결정 기록

눈 감음·45° 장의 용도 (2026-09-18 결정):

| 장 | 용도 | 코드 |
|---|---|---|
| 정면 눈 감음 | **쓴다.** 윗눈꺼풀 선을 눈 축 기준 비율로 저장해 화면 4 에서 눈 감고 그릴 때 테두리를 그 선으로 옮김 | `baseline.ts eyelidRef()` / `eyelidToPx()` |
| 좌·우 45° | **쓴다.** 서버 법선 정밀화 3장에 포함(F-01). 서버가 법선을 안 쓰게 되면(MediaPipe 메시로 대체, 1주차 검증 4) 그때 정면 2장으로 줄인다 | `flow.ts SERVER_SHOTS` |

정면 2장으로 줄이는 조건: 1주차 검증 4에서 MediaPipe 3D 메시만으로 쉐딩 위치가 나오면. 그 전까지 4장 유지.
