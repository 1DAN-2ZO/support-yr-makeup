# 눈 높이 비대칭과 눈꼬리 기울기 — 한국인 사진 분석

**원제** Diagnostic analysis of vertical orbital dystopia and canthal tilt for surgical correction
**저자** Ju-Young Lee, Han-Wool Choung, Pill-Hoon Choung
**발표** J Korean Assoc Oral Maxillofac Surg 2020;46(6):379–384 · [DOI 10.5125/jkaoms.2020.46.6.379](https://doi.org/10.5125/jkaoms.2020.46.6.379)
**라이선스** CC BY-NC 4.0 (원문: `$DHE_DATA_DIR/papers/jkaoms-2020-46-6-379.html`)

> **한 줄**: 한국인 76명의 눈꼬리 기울기를 **0~5° (class I) · 5° 초과 (class II) · 0° 미만 (class III)** 으로 나눴더니, 평균은 약 8.4°, 0~5° 는 14명(평균 3.2°), 0° 미만은 0명이었다.

---

## 무엇을 물었나

눈 높이가 좌우로 다른 것(수직 안와 이소증)을 사진으로 진단하는 방법을 제안하고, 정상인에게서 좌우 차이와 눈꼬리 기울기가 얼마나 되는지 재려 했다. 수술이 필요 없는 사람도 **눈꼬리 기울기를 바꿔** 대칭을 맞출 수 있다고 본다.

## 어떻게

- 한국인 **76명** (남 45 · 여 31, 13~38세, 평균 23.1세) — 얼굴 비대칭으로 내원한 사람
- 정면 사진에서 동공·안쪽·바깥 눈꼬리와 얼굴 중심선을 그어 잼
- 눈꼬리 기울기: 안쪽 눈꼬리 → 바깥 눈꼬리 선과, 안쪽 눈꼬리에서 얼굴 중심선에 수직인 선이 이루는 각
- 분류 (원문): "When the canthal tilt was between 0° and 5°, the participant was considered to have class I canthal tilt; those with canthal tilt of more than 5° were categorized as having class II canthal tilt; and those with canthal tilt under 0° were categorized as having class III tilt."

## 결과

| | 오른쪽 | 왼쪽 |
|---|---|---|
| 전체 (76명) | 8.45° ± 3.53° | 8.42° ± 3.81° |
| class I 0~5° (14명) | 3.21° ± 1.68° | 3.18° ± 1.63° |
| class II 5° 초과 (62명) | 9.60° ± 3.66° | 9.54° ± 2.99° |
| class III 0° 미만 | 0명 | 0명 |

- 좌우 기울기 차이는 모두 2° 미만
- 고찰: 매력적인 한국 얼굴(Rhee et al.)은 8.87° 로 class II. class III 는 "늙고 피곤해 보이게 하며 노년층에 흔하다"

## 한계

- 얼굴 비대칭으로 내원한 사람이라 일반 인구 표본은 아니다. 남녀가 섞여 있다
- class 경계(0° · 5°)를 정한 근거는 따로 밝히지 않았다 — 인상 평가로 정한 값이 아니다

## 우리 프로젝트에 주는 것

**1. 처진 눈 경계 5° 는 이 논문의 class I 경계다.** `personalize.ts` `DROOP_TILT_DEG` = 5 — "평균 기울기 5° 미만 = 처진 눈". Jung 2020(20대 여성 8.4~8.8° ± 3°)으로 보면 **평균 − 1.2 SD, 아래 약 10~12%** 다.

**2. 임상의 "아래로 기운 눈"(0° 미만)은 한국 젊은 층에 거의 없다.** 76명 중 0명, 우리 FFHQ-Makeup 동양인 30장도 0장. 0° 를 경계로 쓰면 처진 눈 가이드가 사실상 아무에게도 안 나간다.

**3. 이 논문이 "class I = 처진 눈"을 말하지는 않는다.** class I 이 처진 눈으로 보인다는 인상 평가는 없다. 그 부분은 사람 표시로 확인했다(`eval/vlm/droop_label.py`, 1명 · 27장): 5° 에서 22장 맞음, 표시에 가장 잘 맞춘 4° 는 23장 — 한 장 차이라 표본에 맞춘 값 대신 논문 경계를 쓴다.

**4. 재는 방법이 다르다.** 논문은 사람이 사진에서 눈꼬리를 찍고 얼굴 중심선 기준으로 잰다. 우리는 MediaPipe 33·133 / 263·362 점을 롤 보정해 잰다. 우리 30장 평균(6.7°)이 논문(8.4°)보다 낮아, 같은 눈이라도 우리 값이 낮게 나올 수 있다 — 팀원 실제 사진으로 다시 맞출 때(#84) 같이 본다.
