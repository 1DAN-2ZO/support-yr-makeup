# 화면 3 POC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 당화응 화면 3(부위 완성본)·3-c(쉐딩·하이라이트 완성본)를 브라우저 POC로 만들어, 부위별 크롭 박스와 얼굴형 규칙 윤곽선을 계산하고 문서의 크롭 가정값이 3:4 셀카에서 성립하는지 실측한다.

**Architecture:** `poc/screen6/`의 관례를 그대로 따른다 — 순수 함수 모듈(`core.js`) + 데이터(`rules.js`) + Node 검증(`tests.mjs`) + 폰 목업과 시연 패널(`index.html`/`app.js`). `core.js`는 DOM·캔버스·MediaPipe를 모르고 랜드마크 숫자만 다루므로 Node에서 합성 픽스처로 전부 검증된다. 브라우저 쪽은 MediaPipe로 랜드마크를 뽑아 `core.js`에 넘기는 얇은 껍데기다.

**Tech Stack:** 순수 ESM JavaScript (빌드 없음), Node 18+ (`node tests.mjs`), MediaPipe Tasks Vision 0.10.14 (CDN, 브라우저만), 정적 서버 `python -m http.server`

**Spec:** `docs/superpowers/specs/2026-09-16-screen3-poc-design.md`

## Global Constraints

- 작업 폴더는 `poc/screen3/`. 다른 폴더의 파일을 고치지 않는다(마지막 Task의 `docs/README.md`·`README.md` 한 줄 갱신만 예외).
- `core.js`는 DOM·캔버스·MediaPipe·`fetch`를 쓰지 않는다. 입력은 랜드마크 배열·이미지 크기·partId·faceShape, 출력은 숫자·문자열뿐이다.
- 얼굴형 판정을 하지 않는다. label은 입력으로 받는다(파트 1 F-02 담당).

```js
// 화면 3(부위 완성본) 핵심 계산 모듈 (순수 함수). 브라우저·Node 공용 ESM.
// DOM·캔버스·MediaPipe를 쓰지 않는다. 랜드마크 숫자만 다룬다.
// 얼굴형 판정은 하지 않는다 — label 을 입력으로 받는다 (파트 1 F-02 담당).

import { SMOKY, CONTOUR_RULES } from './rules.js';

/** 부위 근거 한 줄. contour 는 얼굴형별 멘트. 숫자를 넣지 않는다. */
export function rationale(partId, faceShape = 'oval') {
  if (partId === 'contour') {
    const rule = CONTOUR_RULES[faceShape] || CONTOUR_RULES.oval;
    return rule.rationale;
  }
  const s = SMOKY.rationale[partId];
  if (!s) throw new Error(`알 수 없는 partId: ${partId}`);
  return s;
}

/** "지금 필요한 것: …" 한 줄. */
export function products(partId) {
  const p = SMOKY.products[partId];
  if (!p) throw new Error(`알 수 없는 partId: ${partId}`);
  return `지금 필요한 것: ${p}`;
}
```

```js
export function toPx(landmarks, imgSize, indices) {
  return indices.map((i) => {
    const p = landmarks[i];

export function boundsOf(pts) {
  const xs = pts.map((p) => p[0]), ys = pts.map((p) => p[1]);
  const x = Math.min(...xs), y = Math.min(...ys);
  return { x, y, w: Math.max(...xs) - x, h: Math.max(...ys) - y };

 * 부위 크롭 박스. 여백 적용 → 종횡비 확장 → 경계 처리(축소는 마지막 수단).
 * clamped=true 는 문서의 여백·배수 가정값이 이 사진에서 성립하지 않는다는 신호다.
 */
export function cropSpec(landmarks, imgSize, partId, opts = {}) {
  const orientation = ORIENTATION[partId];
  if (!orientation) throw new Error(`알 수 없는 partId: ${partId}`);
  const aspect = ASPECT[orientation];
  const pts = partLandmarks(landmarks, imgSize, partId);
  const b = boundsOf(pts);

  let w, h;
  if (orientation === 'landscape') {
    w = b.w * (1 + 2 * (opts.sideMargin ?? SIDE_MARGIN));
    h = w / aspect;
  } else {
    w = imgSize.w / (opts.zoom ?? PORTRAIT_ZOOM);
    h = w / aspect;
  }
  // 부위가 박스보다 크면 담을 수 있을 만큼 키운다
  if (b.w > w) { w = b.w; h = w / aspect; }
  if (b.h > h) { h = b.h; w = h * aspect; }

  const cx = b.x + b.w / 2, cy = b.y + b.h / 2;
  const clampedSides = [];
  let clamped = false;

  // 1) 이미지보다 크면 축소 (확대율을 희생)
  if (w > imgSize.w || h > imgSize.h) {
    const k = Math.min(imgSize.w / w, imgSize.h / h);
    w *= k; h *= k; clamped = true;
  }
  // 2) 중심을 유지하되 이미지 안으로 이동
  let x = cx - w / 2, y = cy - h / 2;
  if (x < 0) clampedSides.push('left');
  if (y < 0) clampedSides.push('top');
  if (x + w > imgSize.w) clampedSides.push('right');
  if (y + h > imgSize.h) clampedSides.push('bottom');
  x = clampNum(x, 0, imgSize.w - w);
  y = clampNum(y, 0, imgSize.h - h);

  const covered = pts.every((p) => p[0] >= x - 0.5 && p[0] <= x + w + 0.5 && p[1] >= y - 0.5 && p[1] <= y + h + 0.5);
  return { x, y, w, h, orientation, aspect, zoomRatio: imgSize.w / w, covered, clamped, clampedSides };
}
```

```js
const IRIS_MM = 11.7;

/** 홍채 지름 11.7mm 로 px→mm 척도. poc/app.js 의 irisScale 과 같은 방식. */
export function mmPerPx(landmarks, imgSize) {
  const d = (side) => {
    const p = toPx(landmarks, imgSize, IDX.iris[side]);
    return Math.max(
      Math.hypot(p[0][0] - p[2][0], p[0][1] - p[2][1]),
      Math.hypot(p[1][0] - p[3][0], p[1][1] - p[3][1]),
    );
  };
  const px = (d('r') + d('l')) / 2;
  return px > 2 ? IRIS_MM / px : 0.1;
}

const midOf = (pts) => {
  const n = pts.length || 1;
  return [pts.reduce((a, p) => a + p[0], 0) / n, pts.reduce((a, p) => a + p[1], 0) / n];
};

/** 링 랜드마크를 중심 기준 위/아래로 갈라 폴리라인으로 만든다 (인덱스 추측 없이) */
const halfRing = (pts, which) => {
  const cy = midOf(pts)[1];
  const half = pts.filter((p) => (which === 'upper' ? p[1] <= cy : p[1] >= cy));
  return (half.length >= 2 ? half : pts).slice().sort((a, b) => a[0] - b[0]);
};

/** region 이름 → 폴리라인(픽셀) 배열. 좌우가 나뉘는 부위는 두 개를 돌려준다. */
const REGION_BUILDERS = {
  jawline: (lm, s) => [toPx(lm, s, IDX.jawline)],
  jawCorner: (lm, s) => {
    const j = toPx(lm, s, IDX.jawline);
    const k = Math.max(2, Math.round(j.length / 3));
    return [j.slice(0, k), j.slice(-k)];
  },
  underCheek: (lm, s) => [halfRing(toPx(lm, s, IDX.cheek.r), 'lower'), halfRing(toPx(lm, s, IDX.cheek.l), 'lower')],
  cheekTop: (lm, s) => [halfRing(toPx(lm, s, IDX.cheek.r), 'upper'), halfRing(toPx(lm, s, IDX.cheek.l), 'upper')],
  foreheadSide: (lm, s) => {
    const [top] = toPx(lm, s, [IDX.foreheadTop]);
    const [r] = toPx(lm, s, [IDX.foreheadSide.r]);
    const [l] = toPx(lm, s, [IDX.foreheadSide.l]);
    return [[r, [(r[0] + top[0]) / 2, top[1]]], [l, [(l[0] + top[0]) / 2, top[1]]]];
  },
  foreheadTop: (lm, s) => {
    const [r] = toPx(lm, s, [IDX.foreheadSide.r]);
    const [l] = toPx(lm, s, [IDX.foreheadSide.l]);
    const [top] = toPx(lm, s, [IDX.foreheadTop]);
    return [[[r[0], top[1]], [l[0], top[1]]]];
  },
  chinTip: (lm, s) => {
    const [c] = toPx(lm, s, [IDX.chinTip]);
    const d = s.w * 0.06;
    return [[[c[0] - d, c[1]], [c[0] + d, c[1]]]];
  },
  noseBridge: (lm, s) => [toPx(lm, s, IDX.noseBridge)],
  tZone: (lm, s) => [toPx(lm, s, [IDX.foreheadTop, ...IDX.noseBridge])],
  underEye: (lm, s) => [toPx(lm, s, IDX.underEye.r), toPx(lm, s, IDX.underEye.l)],
};

/** 폴리라인을 법선 방향으로 ±half 밀어 닫힌 밴드 폴리곤으로 만든다. */
function bandFromPolyline(pts, widthPx) {
  if (pts.length < 2) return [];
  const half = widthPx / 2, up = [], dn = [];
  for (let i = 0; i < pts.length; i++) {
    const a = pts[Math.max(0, i - 1)], b = pts[Math.min(pts.length - 1, i + 1)];
    let tx = b[0] - a[0], ty = b[1] - a[1];
    const len = Math.hypot(tx, ty) || 1; tx /= len; ty /= len;
    const nx = -ty, ny = tx;
    up.push([pts[i][0] + nx * half, pts[i][1] + ny * half]);
    dn.push([pts[i][0] - nx * half, pts[i][1] - ny * half]);
  }
  return [...up, ...dn.reverse()];
}

/**
 * 얼굴형 규칙으로 쉐딩·하이라이트 자리를 만든다.
 * 얼굴형 판정은 하지 않는다 — faceShape 는 파트 1(F-02)이 주는 label 이다.
 * 법선 맵이 없으므로 source 는 항상 'landmark_only'.
 */
export function contourOutline(landmarks, imgSize, faceShape = 'oval') {
  const rule = CONTOUR_RULES[faceShape] || CONTOUR_RULES.oval;
  const mm = mmPerPx(landmarks, imgSize);
  const build = (specs) => specs.flatMap(({ region, widthMm }) => {
    const lines = (REGION_BUILDERS[region] || (() => []))(landmarks, imgSize);
    return lines.map((line) => bandFromPolyline(line, widthMm / mm)).filter((p) => p.length >= 4);
  });
  const shading = build(rule.shading);
  const highlight = build(rule.highlight);
  return {
    shading, highlight,
    labels: [
      { text: '쉐딩', anchor: midOf(shading.flat()) },
      { text: '하이라이트', anchor: midOf(highlight.flat()) },
    ],
    source: 'landmark_only',
  };
}
```

```js
import { FaceLandmarker, FilesetResolver } from "https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@0.10.14/vision_bundle.mjs";
import { IDX, partLandmarks, cropSpec, contourOutline, rationale, products } from './core.js';
import { PART_IDS, PART_NAME, ORIENTATION, FACE_SHAPES, FACE_SHAPE_NAME, STATUS_LABEL } from './rules.js';

const $ = (id) => document.getElementById(id);
const SAMPLES = '../../danghaeung_poc_3x4_20/';
const PERSONS = [1, 2, 3, 4, 5];
const SHOTS = ['front_open', 'front_closed', 'left_45', 'right_45'];
export const SAMPLE_FILES = PERSONS.flatMap((p) => SHOTS.map((s) => `person_${p}_${s}.jpg`));

const state = { landmarker: null, current: null, partId: 'liner', faceShape: 'round', statuses: {} };

async function initLandmarker() {
  const files = await FilesetResolver.forVisionTasks("https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@0.10.14/wasm");
  const opts = (delegate) => ({
    baseOptions: { modelAssetPath: "https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task", delegate },
    runningMode: "IMAGE", numFaces: 1,
  });
  try { state.landmarker = await FaceLandmarker.createFromOptions(files, opts("GPU")); }
  catch { state.landmarker = await FaceLandmarker.createFromOptions(files, opts("CPU")); }
}

async function loadImage(src, name) {
  const img = new Image();
  await new Promise((res, rej) => { img.onload = res; img.onerror = rej; img.src = src; });
  const cv = document.createElement('canvas');
  cv.width = img.naturalWidth; cv.height = img.naturalHeight;
  cv.getContext('2d').drawImage(img, 0, 0);
  const det = state.landmarker.detect(cv);
  return { name, img: cv, size: { w: cv.width, h: cv.height }, landmarks: det.faceLandmarks?.[0] || null };
}

const IDX_COLORS = { brow: '#C2731F', liner: '#2A8C85', shadow: '#7A6CC2', lip: '#B8432F', cheek: '#2F7FB8', contour: '#2B2B2B' };

function drawIndexCheck(shot) {
  const cv = $('cvIndex'), ctx = cv.getContext('2d');
  const k = Math.min(cv.width / shot.size.w, cv.height / shot.size.h);
  ctx.clearRect(0, 0, cv.width, cv.height);
  ctx.drawImage(shot.img, 0, 0, shot.size.w * k, shot.size.h * k);
  if (!shot.landmarks) return;
  for (const id of PART_IDS) {
    ctx.fillStyle = IDX_COLORS[id];
    for (const [x, y] of partLandmarks(shot.landmarks, shot.size, id)) {
      ctx.beginPath(); ctx.arc(x * k, y * k, 2, 0, Math.PI * 2); ctx.fill();
    }
  }
}

async function selectShot(name) {
  $('photoInfo').textContent = '검출 중…';
  const shot = await loadImage(SAMPLES + name, name);
  state.current = shot;
  $('photoInfo').textContent = shot.landmarks
    ? `${name} · ${shot.size.w}×${shot.size.h} · 얼굴 검출됨`
    : `${name} · 얼굴을 찾지 못함`;
  drawIndexCheck(shot);
  render();
}

function render() { /* Task 5 에서 채운다 */ }

function initUI() {
  const sel = $('sampleList');
  sel.innerHTML = SAMPLE_FILES.map((f) => `<option value="${f}">${f}</option>`).join('');
  sel.onchange = () => selectShot(sel.value);
  $('fileUp').onchange = async (e) => {
    const f = e.target.files[0]; if (!f) return;
    const url = URL.createObjectURL(f);
    const shot = await loadImage(url, f.name);
    URL.revokeObjectURL(url);
    state.current = shot;
    $('photoInfo').textContent = shot.landmarks ? `${f.name} · 얼굴 검출됨` : `${f.name} · 얼굴을 찾지 못함`;
    drawIndexCheck(shot); render();
  };
  const fs = $('faceShape');
  fs.innerHTML = FACE_SHAPES.map((f) => `<option value="${f}">${FACE_SHAPE_NAME[f]}</option>`).join('');
  fs.value = state.faceShape;
  fs.onchange = () => { state.faceShape = fs.value; render(); };
  document.querySelectorAll('nav .tab').forEach((t) => {
    t.onclick = () => {
      document.querySelectorAll('nav .tab').forEach((x) => x.classList.remove('active'));
      t.classList.add('active');
      const map = { photo: 'tabPhoto', part: 'tabPart', verify: 'tabVerify' };
      for (const [k, elId] of Object.entries(map)) $(elId).hidden = (k !== t.dataset.tab);
    };
  });
  $('btnFixtures').onclick = buildFixtures;
}

async function buildFixtures() {
  const out = {};
  for (const f of SAMPLE_FILES) {
    const shot = await loadImage(SAMPLES + f, f);
    if (!shot.landmarks) { $('testOut').textContent += `\n${f}: 얼굴 검출 실패`; continue; }
    out[f] = { size: shot.size, landmarks: shot.landmarks.map((p) => ({ x: +p.x.toFixed(6), y: +p.y.toFixed(6) })) };
    $('testOut').textContent = `fixtures 생성 중… ${Object.keys(out).length}/${SAMPLE_FILES.length}`;
  }
  const blob = new Blob([JSON.stringify(out)], { type: 'application/json' });
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob); a.download = 'fixtures.json'; a.click();
  $('testOut').textContent = `fixtures.json 생성 완료 (${Object.keys(out).length}장). poc/screen3/ 에 저장하세요.`;
}

initLandmarker().then(() => { initUI(); selectShot(SAMPLE_FILES[0]); });
```

```js
/** 원본 픽셀 폴리곤을 크롭 박스 좌표로 옮겨 점선 테두리만 그린다. 면 채우기 없음. */
function drawContour(canvas, shot, crop, faceShape) {
  const ctx = canvas.getContext('2d');
  const o = contourOutline(shot.landmarks, shot.size, faceShape);
  const sx = canvas.width / crop.w, sy = canvas.height / crop.h;
  const toLocal = (p) => [(p[0] - crop.x) * sx, (p[1] - crop.y) * sy];

  ctx.lineWidth = 2;
  ctx.setLineDash([6, 5]);
  for (const [polys, color] of [[o.shading, '#2A8C85'], [o.highlight, '#7FC3BD']]) {
    ctx.strokeStyle = color;
    for (const poly of polys) {
      ctx.beginPath();
      poly.map(toLocal).forEach((p, i) => (i ? ctx.lineTo(p[0], p[1]) : ctx.moveTo(p[0], p[1])));
      ctx.closePath(); ctx.stroke();
    }
  }
  ctx.setLineDash([]);
  ctx.font = '600 13px system-ui'; ctx.textAlign = 'center';
  for (const l of o.labels) {
    const [x, y] = toLocal(l.anchor);
    const w = ctx.measureText(l.text).width + 10;
    ctx.fillStyle = 'rgba(255,255,255,.85)';
    ctx.fillRect(x - w / 2, y - 9, w, 18);
    ctx.fillStyle = '#2B2B2B';
    ctx.fillText(l.text, x, y + 4);
  }
}
```

```js
// 샘플 20장 × 부위 6개 실측 — node report.mjs
import { readFileSync } from 'node:fs';
import { cropSpec } from './core.js';
import { PART_IDS, PART_NAME, PORTRAIT_ZOOM, SIDE_MARGIN } from './rules.js';

const fx = JSON.parse(readFileSync(new URL('./fixtures.json', import.meta.url)));
const rows = [];
for (const [name, { size, landmarks }] of Object.entries(fx)) {
  for (const id of PART_IDS) {
    const c = cropSpec(landmarks, size, id);
    rows.push({ name, id, zoom: c.zoomRatio, covered: c.covered, clamped: c.clamped, sides: c.clampedSides.join(','), w: Math.round(c.w), h: Math.round(c.h) });
  }
}

console.log(`샘플 ${Object.keys(fx).length}장 × 부위 ${PART_IDS.length}개 = ${rows.length} 케이스`);
console.log(`가정값: 가로 여백 ${SIDE_MARGIN * 100}%, 세로 확대 ${PORTRAIT_ZOOM}배\n`);
console.log('부위\t확대율(최소/중앙/최대)\tcovered\tclamped');
for (const id of PART_IDS) {
  const r = rows.filter((x) => x.id === id);
  const z = r.map((x) => x.zoom).sort((a, b) => a - b);
  const med = z[Math.floor(z.length / 2)];
  const cov = r.filter((x) => x.covered).length, cla = r.filter((x) => x.clamped).length;
  console.log(`${PART_NAME[id]}\t${z[0].toFixed(2)} / ${med.toFixed(2)} / ${z[z.length - 1].toFixed(2)}\t${cov}/${r.length}\t${cla}/${r.length}`);
}

const bad = rows.filter((x) => !x.covered || x.clamped);
if (bad.length) {
  console.log(`\n문제 케이스 ${bad.length}건:`);
  for (const b of bad) console.log(`  ${b.name} ${PART_NAME[b.id]} zoom=${b.zoom.toFixed(2)} covered=${b.covered} clamped=${b.clamped} sides=${b.sides}`);
  console.log('\n→ README 의 실측 결과에 이 표와, 어떤 여백·배수 값이면 0건이 되는지 제안을 적는다.');
} else {
  console.log('\n문제 케이스 0건. 문서의 가정값이 이 샘플에서 성립한다.');
}
```

`tests-browser.js`:

```js
// 검증 탭 러너. tests.mjs 와 같은 케이스(tests-cases.js)를 브라우저에서 돌린다.
import { CASES } from './tests-cases.js';

export function runTests() {
  const out = [];
  for (const [name, fn] of CASES) {
    try { fn(); out.push(`PASS  ${name}`); }
    catch (e) { out.push(`FAIL  ${name}\n      ${e.message}`); }
  }
  const pass = out.filter((l) => l.startsWith('PASS')).length;
  return `${out.join('\n')}\n\n${pass}/${CASES.length} passed`;
}
```

```js
async function runBatch() {
  const rows = [];

    for (const id of PART_IDS) rows.push({ f, id, c: cropSpec(shot.landmarks, shot.size, id) });

    `</table><div class="muted">covered ${cov}/${rows.length} · clamped ${cla}/${rows.length}</div>`;
```
